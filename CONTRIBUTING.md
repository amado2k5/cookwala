# Contributing

Thanks for helping build Cookwala.

- **Recipes:** add or improve `*.cookwala.json` files. Run `cookwala validate` and
  `cookwala simulate` (once tools ship); include the source and license; never copy
  copyrighted text or photos.
- **Vocabularies:** add ingredients, ops, equipment, sensors or hazards with labels in as
  many languages as you can, plus links (Wikidata, FoodOn, USDA FDC).
- **Policy packs:** cite the legal source and effective date for every rule; mark
  `reviewStatus` honestly.
- **Device adapters and bindings:** reserve an `x-<vendor>` namespace in
  `vocab/namespaces.json`.
- **Spec changes:** follow the RFC process in [GOVERNANCE.md](GOVERNANCE.md).

By contributing you agree your contribution is licensed under this repo's licenses (see
README) and covered by the [patent pledge](PATENTS.md).
