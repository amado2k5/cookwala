# Опубликованные нами критические замечания

Мы задали сложные вопросы о Cookwala и записали ответы. Каждое опасение имеет id в [action plan's concern register](ACTION-PLAN.md#2-concern-register), вместе с нашим ответом и его статусом. Внешние отзывы приветствуются и будут перечислены здесь.

## Будет ли это работать? (strategy)

| Проблема | Краткий ответ | Статус |
|---|---|---|
| Рынка еще не существует; спецификация опережает продукты | Small Core, сначала демо, никаких новых спецификаций без пользователей | Core 0.2 выполнено; следующим будет демо устройства |
| У влиятельных игроков нет причин для внедрения | Вести за собой через выгоду каждого участника; полезно без роботов | Ищутся пилотный проект для food bank и партнер по устройствам |
| Симуляторы доказывают то, что они assume | Справедливый baseline, диапазоны, метки "illustrative"; пилоты заменят их | Open |
| Голод — это вопрос бедности и конфликтов, а не surplus | Cookwala вносит вклад; она не претендует на то, чтобы покончить с голодом в одиночку | Сообщение изменено |
| Безопасность, ответственность и поверхность атаки | Ограничения принудительно применяются на устройстве; refusal; recalls; отчеты об инцидентах | Спецификация готова; review certifier open |
| Конфиденциальность (данные о здоровье и религии, реестры против удаления) | Local-first, выборочное раскрытие, логи только с хешами, согласие | Спецификация готова; impact assessment open |
| Слишком сложно | Core 0.2; все остальное помечено как experimental | Done |
| Зависимость от основателя | Путь управления к нейтральному дому | GOVERNANCE.md |

## Является ли технический проект надежным?

| Проблема | Что изменилось в Core 0.2 |
|---|---|
| Операции не имели физического смысла | Envelopes, уровни тепла, sensor ladders, правило высоты, тестовые векторы |
| Ошибки в единицах и числах | Только °C, абсолютные допуски, кухонные единицы, плотности, десятичные денежные значения |
| Схемы принимали опечатки | Строгие схемы с расширениями `x-`; offline bundle |
| Один изменяемый документ Mission | Event log + projection, единый секвенсор, таблица переходов |
| Реестр давал мало данных | Ключевые записи с отзывом, подтвержденные контрольные точки, обнаружение перезаписи |
| Неопределенная доставка событий; безопасность в шине | Порядковые номера, классы задержки, heartbeats, "safety is local" |
| Дрейф API surfaces | Core OpenAPI; каждая ссылка проверяется в CI |
| Отсутствие верификатора | Справочная библиотека и 106 векторов conformance |

## Отзывы, которые мы запрашиваем

W3C TAG (identity, JSON-LD), IETF SCITT (event-log transparency), ученые-пищевики
(envelopes), специалисты по пищевой безопасности и диетологи (rule packs), аудит безопасности,
обзор защиты данных и анализ пробелов сертифицирующего органа. См.
[external review program](ACTION-PLAN.md#5-external-review-program-sequenced).
