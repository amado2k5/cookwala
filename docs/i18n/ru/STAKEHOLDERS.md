# Стейкхолдеры: сообщение, варианты, первый успех и поток для каждого

**Статус:** 2026-10-04. Для каждой группы: почему Cookwala важна для них, способы взаимодействия от легких до глубоких, первый успех менее чем за 15 минут, путь после него и то, как взаимодействие продвигает их работу и мир. Здесь нет упоминаний партнера, пользователя или пилотного проекта, которых не существует. Там, где что-то планируется, указано next или later.

Три цели, стоящие за каждой строкой: помочь покончить с голодом, сделать людей здоровее, поставить роботов на службу людям.

---

## 1. Builders: разработчики, производители роботов и бытовой техники, инженеры встраиваемых систем, создатели AI-агентов, разработчики умного дома и платформ, контрибьюторы open-source

**Сообщение.** Роботы и бытовые приборы учатся двигаться. Никто не записал в форме, которую может проверить машина, что означает «simmer», когда курица становится безопасной или когда шаг должен быть отклонен (refusal before heat). Cookwala — это тот самый слой: рецепты, которые машина может планировать, конечные условия, которые она может измерить, и пределы безопасности, которые она накладывает на саму себя. Это открытое, безвозмездное, модельно-нейтральное и аппаратно-нейтральное решение, которое поставляется с набором для conformance, который вы можете запустить уже сегодня.

**Варианты.**
- *Light:* выполнить браузерный dry run; прочитать Core 0.2 (один вечер).
- *Medium:* `pip install -e sdk/python`, выполнить dry run возможностей вашего устройства на примере рецептов, запустить векторы conformance, запустить reference hub.
- *Deep:* реализовать Core API на устройстве или на hub, опубликовать отчет conformance, добавить ваше устройство в directory, предложить RFC, написать узел ROS 2 bridge, добавить сценарии атак в agent-safety benchmark.

**Первый успех (менее 15 минут).**
```bash
git clone https://github.com/amado2k5/cookwala && cd cookwala && pip install -e sdk/python
cookwala dryrun examples/koshari.cookwala.json --device examples/capabilities/robot-arm.json
# refused: cw.op.boil, missing_capability (and later: no oil thermometer, no deep frying)
cookwala dryrun examples/koshari.cookwala.json --device examples/capabilities/robot-arm.json --human-present
cookwala conformance --report report.json          # 106 vectors; a signed-ready report
```

**Поток.** Dry run → внедрить Core API в отношении reference hub → пройти conformance →
опубликовать отчет → перечислить устройство → согласованные execution logs становятся наборами данных LeRobot и
трассировками OpenTelemetry.

**Как это продвигает их работу.** Общее определение задачи и тест на успех для приготовления пищи с публичным бенчмарком для сравнения; рецепты любой кухни без их написания; история безопасности, которую могут прочитать регуляторы; отчеты о conformance как документ для продаж; статус первопроходца в стандарте, которым будут управлять его исполнители.

**Как это развивает общество.** Меньше кухонных пожаров и пищевых отравлений благодаря машинам, которые проявляют refusal before heat, а не гадают; машинам, которые наследуют мировые кухни, а не только несколько.

## 2. Компании: стартапы, предприятия, пищевые компании, продуктовые ритейлеры и службы доставки, рестораны и службы общественного питания, страховщики, сертифицирующие органы, отделы продаж и партнерства

**Сообщение.** Каждая компания, имеющая дело с продуктами питания, столкнется с кухонными машинами и ИИ-агентами в ближайшие несколько лет. Cookwala предоставляет вам единый интерфейс для всех них — единственный, где ограничения безопасности соблюдаются на самом устройстве, а записи доступны для аудита. Для продуктовых ритейлеров и служб доставки: получение временных окон доставки и требований по аллергенам, а не расписания семьи. Для страховщиков и сертифицирующих органов: формат отчета о conformance и лента отчетов об инцидентах, разработанные специально для вас.

**Варианты.**
- *Light:* прочитайте страницу Investors and partners и страницы trust; сопоставьте ваши продукты с
  классами ингредиентов и операциями.
- *Medium:* опубликуйте фид предложений (market profile, experimental) или предложение surplus для
  локальной программы (Humanitarian Profile); запустите agent-safety benchmark на агенте, который вы
  планируете развернуть.
- *Deep:* внедрите Core API в продукт; спонсируйте conformance verification; вступите в
  steering committee, когда он будет сформирован; примите путь certification.

**Первый успех.** Преобразуйте одну линейку продуктов в рыночное `Offer` с GTIN и учетными данными по аллергенам, проведите валидацию и посмотрите, какие примеры рецептов она может обеспечить.

**Flow.** Предложить корм → derived constraints от домохозяйств → заказы через ваш собственный checkout → события выполнения → репутация на основе execution reports (с согласия).

**Как это продвигает их работу.** Доступ к нейтральному слою вместо дюжины интеграций с вендорами; сигналы спроса (later, после проверки на соответствие антимонопольному законодательству), которые сокращают отходы; certification, которую страховщики могут оценить; публичный реестр безопасности.

**Как это развивает общество.** Меньше еды теряется между магазином и тарелкой; surplus достигает кухонь до того, как она сгниет; машины в домах, с которыми невозможно договориться о небезопасных действиях.

## 3. Поставщики: бакалейные магазины, фермы и кооперативы, доставка, поставщики энергии, ИИ и моделей, издатели рецептов

**Сообщение.** Провайдеры подключаются к Cookwala как пиры, а не как арендаторы. Продавец продуктов или служба доставки получает ограничение, но никогда — факты о домохозяйстве. Поставщик ИИ получает бенчмарк, который показывает, что его модель безопасна на кухне, и MCP-сервер для использования сегодня. Издатель рецептов сохраняет свое имя в каждом рецепте и может публиковать подписанный каталог из статической папки.

**Options.** Опубликовать каталог (рецепты) · опубликовать ленту предложений · запустить agent-safety benchmark · запустить registry node · предложить surplus через SMS.

**Первый успех.** Издатель рецептов: `cookwala init my-dish`, редактирование, `cookwala validate`,
`cookwala hash`; ваш каталог — это папка с `/.well-known/cookwala.json`. Поставщик ИИ:
добавьте MCP server и запустите десять случаев agent-safety.

**Flow.** Каталог или фид → запись в registry под вашим подтвержденным namespace → recall фида, если
что-то идет не так → репутация на основе результатов.

**Как это продвигает их работу.** Охватите каждое устройство и агента через один формат;
кредит и происхождение через подпись; стандарт безопасности, который является маркетинговым активом при
честном прохождении.

**Как это развивает общество.** Рецепты остаются закрепленными за авторами; агенты, действующие от имени людей, проходят стадию measured, прежде чем им начнут доверять.

## 4. Еда: фермеры, повара и шеф-повара, домашние кулинары, создатели рецептов, кулинарные школы

**Сообщение.** Рецепт, написанный для Cookwala, сохраняет ваше имя и вашу кухню на каждом устройстве, которое его готовит, с записанными шагами, которые машина никогда не должна пропускать. Ферма с излишком может указать его через SMS и достичь кухни в тот же день. Кулинарная школа может обучать пищевой безопасности с помощью формата, который проверяет сам себя.

**Варианты.**
- *Фермеры:* `FARM 120KG TOMATO A BB0411` в шлюз программы (если он существует);
  later, считывайте сигналы спроса и предложения.
- *Повара и шеф-повара:* превратите один рецепт, который вы знаете наизусть, в рецепт Cookwala; проверьте
  предложения с описанием шагов на вашем языке; later, записывайте сессии с согласием с начислением кредитов.
- *Школы:* используйте девять примеров рецептов в качестве учебных случаев; добавляйте свои собственные.

**Первый успех.** Повара: `cookwala init`, напишите один рецепт с условием завершения для каждого шага нагрева, проведите валидацию. Фермеры: отправьте одно SMS-предложение программе, которая запускает профиль (пока ничего не запущено; парсер и векторы существуют).

**Поток.** Рецепт → validation → catalog → dry run на устройствах → execution logs показывают, как это работает на реальных машинах → revisions с доказательствами.

**Как это продвигает их работу.** Атрибуция, которая перемещается; рецепт, который могут готовить машины в других странах; для фермеров — способ превратить surplus в еду вместо отходов.

**Как это развивает общество.** Кулинарное наследие сохраняется как рабочее знание, а не видео;
меньше отходов на уровне фермерских хозяйств.

## 5. Гуманитарная сфера: НПО, food banks, общественные кухни, программы школьного питания, агентства по оказанию помощи, доноры

**Сообщение.** Humanitarian Profile перемещает surplus food на тарелки с помощью телефонов и электронных таблиц, регистрирует проверки холодовой цепи, подсчитывает количество приемов пищи и **не содержит персональных данных**. Он работает без роботов, приложений или интернета. Он дает вам цифры, которые вы можете защитить: спасенные килограммы, поданные приемы пищи, показатель соответствия нормам питания, стоимость одного приема пищи, время на получение, инциденты с безопасностью, каждый с указанием своего метода.

**Варианты.**
- *Light:* прочитайте профиль и протокол пилотного проекта; попробуйте SMS walkthrough.
- *Medium:* запустите CSV шаблоны на одном объекте в течение четырех недель (уровень H0) и вычислите
  summary влияния.
- *Deep:* 12-недельный предварительно зарегистрированный пилотный проект с базовой линией и независимым оценщиком;
  адаптируйте rule packs к национальному законодательству совместно с вашим руководителем по пищевой безопасности; запустите свой собственный узел registry.

**Первый успех.** Заполните три шаблона CSV на один день, запустите
`cookwala humanitarian --summary your-folder`, прочитайте `ImpactSummary` с методом под
каждым числом.

**Поток.** Предложение → запрос → передача с проверкой температуры → распределение → резюме воздействия → опубликованные результаты, что бы они ни показывали.

**Как это продвигает их работу.** Сопоставимые показатели по разным площадкам; доказательства для спонсоров;
выводы по безопасности до, а не после возникновения проблемы; формат, который системы доноров могут считывать (сопоставления HXL,
GS1, DHIS2).

**Как это развивает общество.** Больше еды безопасно доходит до людей, с сохранением их достоинства:
без имен, без лиц, без профилирования.

## 6. Здоровье: диетологи, специалисты по пищевой безопасности, агентства общественного здравоохранения, дома престарелых

**Сообщение.** Правила питания и пищевой безопасности в виде проверяемых машиной rule pack, полученных на основе общественных рекомендаций, применяемых к меню и передачам, с вашим обзором, записанным по профессии и результату. Ничто не является медицинской консультацией; ничто не утверждается сверх того, что сказано в rule pack.

**Options.** Просмотрите pack с помощью шаблона (два часа) · адаптируйте pack к национальным правилам ·
предложите правила ухода для людей, которым вы служите · later, прочитайте агрегированные результаты программ.

**Первый успех.** Откройте `profiles/humanitarian/care-vulnerable-groups.rulepack.json` и
шаблон проверки; отметьте три правила как одобренные, измененные или отклоненные; сохраните проверку.

**Поток.** Draft pack → review → status reviewed → programs adopt → findings in every
distribution → outcomes published with methods.

**Как это продвигает их работу.** Ваше руководство действует на каждой кухне, которая его внедряет,
включая роботизированные кухни, с фиксацией вашей профессии; публикуемым обзором;
набором данных с результатами (агрегированным, без персональных данных) для исследований.

**Как это развивает общество.** Меньше натрия, сахара и насыщенных жиров в массовых рационах; более безопасное горячее удержание и охлаждение; забота о детях и пожилых людях, заложенная в машину.

## 7. Образование: школьные учителя, педагоги, профессора, исследователи, студенты

**Сообщение.** Приготовление пищи — это самый знакомый процесс в мире, и Cookwala превращает его в
объект обучения: температуры, единицы измерения, справедливое распределение, безопасность, машины, которые следуют правилам. Для
исследователей это бенчмарк, формат набора данных и список открытых проблем.

**Варианты.**
- *Преподаватели:* учебный комплект (`docs/education/LESSON-KIT.md`): пять уроков от «что такое simmer» до «чего машина никогда не должна делать».
- *Профессора и студенты:* список тем для исследований, симуляторы, векторы conformance в качестве тестовых условий, экспорт LeRobot, открытые проблемы масштаба диссертации.
- *Исследователи:* публикация наборов данных согласованных executions; критика assumptions симуляторов; предложение векторов.

**Первый успех.** Преподаватели: проведите dry run браузера в классе и спросите, почему устройство отказало. Студенты: измените одно assumed значение в симуляторе города и объясните результат.

**Поток.** Lesson → project → dataset → paper → RFC.

**Как это продвигает их работу.** Бесплатные, открытые, цитируемые материалы; бенчмарк, который никому не принадлежит;
соавторство в стандарте через RFCs.

**Как это развивает общество.** Поколение, которое знает, что такое безопасная кухня, и умеет читать лист безопасности.

## 8. Правительство: правительства, министерства, городские чиновники, регуляторы, политики и законодатели, управляющие и нормативные органы

**Сообщение.** Домашние и коммерческие кухонные машины поступают на рынок в соответствии с правилами, написанными отдельно для бытовых приборов и программного обеспечения. Cookwala дает регуляторам нечто конкретное, на что можно сослаться: пределы безопасности, соблюдаемые устройством, refusal before heat, подписанные записи, анонимную отчетность об инцидентах и набор средств conformance, который может запустить кто угодно. Для безопасности передачи продуктов питания она предоставляет стандарт данных без персональных данных. Она является безвозмездной и стремится к нейтральному управлению.

**Варианты.** Прочитайте аналитическую записку (`docs/policy/BRIEF.md`) · используйте модельный язык для данных о пожертвовании еды и безопасности кухонных машин · попросите ваш орган по стандартизации рассмотреть Core 0.2 · запустите национальный узел registry · профинансируйте пилотный проект с вашей программой школьного питания.

**Первый успех.** Прочитайте двухстраничную сводку и проверьте три вещи в репозитории:
пакет лимитов безопасности, conformance runner, гуманитарные правила защиты данных.

**Поток.** Кратко → проверка национальным органом по стандартизации → ссылка в руководстве → пилотный проект →
схема certification.

**Как это продвигает их работу.** Готовая, подлежащая проверке техническая база; доказательства из
пилотных проектов; канал взаимодействия с индустрией через нейтральный стандарт; совместимость с
гуманитарными стандартами данных, которые вы уже используете.

**Как это развивает общество.** Более безопасные машины в домах; спасение еды, которое защищает людей, которым оно служит; меньше отходов в городах.

## 9. Капитал: инвесторы, предприниматели, филантропы, банки развития

**Сообщение.** Приготовление пищи вот-вот станет инфраструктурой. Стандарт бесплатен; услуги вокруг него — это бизнес: certification, программное обеспечение hub, согласованные наборы данных, операции registry, пилотные проекты. Гуманитарный уровень — это общественное благо, которое доноры развития могут поддержать с помощью предварительно зарегистрированной оценки. Никаких финансовых обещаний нигде на этом сайте не дается.

**Варианты.** Ознакомьтесь с возможностями, бизнес-моделью, дорожной картой, рисками и управлением
(`/investors`) · профинансируйте dry run или проверку · поддержите компанию, которая продает услуги рядом с
бесплатным стандартом · присоединяйтесь к управлению в качестве наблюдателя от спонсора.

**Первый успех.** Прочитайте разделы whitepaper «проблема», «архитектура» и «риски», а также реестр опасений action plan; каждый открытый риск указан в списке.

**Поток.** Доказательства (пилоты, conformance, пользователи) → этапы в плане действий → финансирование, привязанное к этапам → нейтральная основа для стандарта, компания для услуг.

**Как это продвигает их работу.** Ранняя позиция в определяющем категорию стандарте с честными цифрами; инвестиционно привлекательная сервисная компания, отделенная от общественного блага.

**Как это развивает общество.** Капитал направляется на то, что является measured, а не на то, что является claimed.

## 10. Мысль: философы, этики, историки и футурологи

**Сообщение.** Когда машина готовит рецепт бабушки, кому принадлежит знание? Что означает достоинство в автоматизированном уходе? Что может знать робот домохозяйства, и кто еще может это знать? Cookwala сделала выбор в отношении этих вопросов в коде; эссе (`docs/essays/`) говорят о том, какими они были, и приглашают к несогласию.

**Options.** Прочитать эссе · написать ответ · предложить правило (RFC — это философский
аргумент со схемой) · войти в состав комитета по этической экспертизе профиля household context.

**Первый успех.** Прочитайте эссе о household data и правила перемещения в facet registry;
найдите один facet, чей default вы бы изменили, и объясните почему.

**Поток.** Эссе → публичный комментарий → RFC → измененное значение по умолчанию.

**Как это продвигает их работу.** Живой пример того, как этические позиции становятся действующими правилами,
с публичным протоколом аргументации.

**Как это развивает общество.** Решения о конфиденциальных данных и культурном наследии, принимаемые открыто до того, как машины появятся в миллионах домов.

## 11. Все: люди, которые заботятся о еде, отходах, рабочих местах, климате и будущем

**Сообщение.** Cookwala — это способ записи рецепта так, чтобы любой человек или любой предмет мог приготовить его безопасно, а также способ сделать так, чтобы еда, которая была бы выброшена, попала к тому, кто в ней нуждается. Это бесплатно, это не принадлежит никакой компании, и это говорит о том, чего оно не знает.

**Варианты.** Попробуйте dry run · запустите симулятор · прочитайте рецепты · напишите один рецепт, который вы любите · следуйте дорожной карте · расскажите об этом food bank или школе.

**Первый успех.** Измените устройство в dry run и посмотрите, как один шаг будет отклонен; прочитайте почему.

**Поток.** Любопытство → один рецепт → один разговор с кухней, которая могла бы его использовать.

**Как это улучшает их жизнь.** Более безопасные машины в доме, сохраненные собственные рецепты, способ помочь, не давая денег.

**Как это развивает общество.** Меньше отходов, более безопасная еда, машины, которые служат людям, не способным готовить самостоятельно, и возвращенное человеческое время.

## 12. Рабочие места и достоинство, говоря прямо

Кулинарные машины изменят работу. Позиции Cookwala: люди всегда могут готовить; первые
использования предназначены для людей, которые не могут готовить сами, и для общественных кухонь, которым
не хватает рук; имя повара остается в рецепте, где бы он ни готовился; голос работника имеет
место в руководящем комитете; новые роли (инженеры рецептов, техники по обслуживанию пищевых роботов,
сертификаторы, рецензенты rule pack) названы без обещания конкретного количества.
