# شرکاء: یو پیغام، انتخابونه، لومړنی بریالیتوب او د هرچا لپاره یو جریان

**Status:** 2026-10-04. د هرې ډلې لپاره: ولې Cookwala دوی ته اهمیت لري، له سپک څخه تر ژورې پورې د ښرګو (engage) کولو لارې چارې، په ۱۵ دقیقو کې لومړی بریالیتوب، ورپسې لاره، او څنګه ښرګېدل د دوی کار او نړۍ پرمختګ ته رسوي. دلته هیڅ یو داسې شریک، کاروونکی یا پایلو (pilot) نوم نه دی چې अस्तितز نه لري. چیرته چې څه پلان شوي وي، هلته `next` یا `later` لیکل شوي دي.

هر یو کرښې تر شا درې موخې: د وږنګۍ په پای ته رسولو کې مرسته کول، خلک روغتیاور کول، او روبوټونه د خلکو لپاره په کار اچول.

## 1. جوړونکي: ډیویلپران، روبوټ او وسایل جوړونکي، ایمبیډډ انجنیران، AI-agent جوړونکي، اسمارټ-هوم او پلیټ فارم ډیویلپران، اوپن-سورس مرسته کوونکي

**پیغام.** روبوټونه او وسایل حرکت کول زده کوي. هیڅوک په داسې بڼه کې نه دي لیکلي چې یو ماشین یې چک کولی شي، چې "simmer" څه معنی لري، کله د چرګ غوښه خوندي ده، یا کله باید یو ګام رد شي. Cookwala هغه تیره (layer) ده: هغه ترکیبونه چې یو ماشین یې پلان کولی شي، هغه پای ته رسېدنې چې هغه یې اندازه کولی شي، او هغه خوندیتوب چې هغه پر خپل ځان پلي کوي. دا خلاص، بې له سلطې (royalty-free)، ماډل ته بې پروا (model-neutral) او وسیلې ته بې پروا (device-neutral) دی، او د یو conformance suite سره راځي چې تاسو یې نن مشر کولی شئ.

**لارې چارې.**
- *Light:* د براوزر dry run چلول؛ Core 0.2 ولولئ (یو ماښام).
- *Medium:* `pip install -e sdk/python`، د خپل وسیلې وړتیاوې د نمونه ریسیپيانو په وړاندې dry-run کړئ، د conformance وېکتورونه چلول، د مرجع hub پیلول.
- *Deep:* په یو وسیلې یا hub باندې Core API پلي کړئ، د conformance راپور خپاره کړئ، خپله وسیله directory ته اضافه کړئ، یو RFC وړاندیز کړئ، یو ROS 2 bridge node ولیکئ، د agent-safety benchmark ته د برید حالتونه (attack cases) اضافه کړئ.

**لومړۍ بریا (د ۱۵ دقیقو لاندې).**
```bash
git clone https://github.com/amado2k5/cookwala && cd cookwala && pip install -e sdk/python
cookwala dryrun examples/koshari.cookwala.json --device examples/capabilities/robot-arm.json
# refused: cw.op.boil, missing_capability (and later: no oil thermometer, no deep frying)
cookwala dryrun examples/koshari.cookwala.json --device examples/capabilities/robot-arm.json --human-present
cookwala conformance --report report.json          # 106 vectors; a signed-ready report
```

**Flow.** Dry run → reference hub په وړاندې Core API پلي کړئ → conformance پاس کړئ →
راپور خپره کړئ → وسیله لیست کړئ → رضایت شوي execution logs د LeRobot datasets او
OpenTelemetry traces کیږي.

**دا څنګه د دوی کار مخکې وړي.** د پخلي لپاره یو ګډ دنده تعریف او د بریالیتوب ازموینه، په کې یو عام معیار شامل دی چې د اندازه کولو لپاره کارول کیږي؛ په هر ډول خوراک کې ترکیبونه پرته له دې چې هغه ولیکل شي؛ یو د خوندیتوب کیسه چې مقررات کونکي یې په لاس کې ونیسي؛ د conformance راپورونه د پلور د سند په توګه؛ په یو معیار کې د لومړني ګام اخیستونکي حیثیت چې د هغې د پلي کونکو لخوا اداره به کیږي.

**دا څنګه ټولنه پرمختګ ته رسوي.** د پخلنځي کمه اورېاوې او د خوراک څخه د ناروغیو کمښت د هغو ماشینونو له امله چې د اټکل پر ځای انکار کوي؛ هغه ماشینونه چې د لږو پر ځای د نړۍ خوراکونه يرثوي.

## 2. شرکتونه: پیالوې (startups)، بنسټونه، د خوراکي توکو شرکتونه، د خوراکي توکو پلورونکي او ډیلیوري، رستورانتونه او د خوراکي توکو خدمتونه، بیمه کونکي، تاییدونکي، د پلور او شراکت ټیمونه

**پیغام.** هر هغه شرکت چې له خوراکي توکو سره کار کوي، په راتلونکو څو کلونو کې د پخلي ماشینونو او AI agents سره مخ کېږي. Cookwala تاسو ته د هغوی ټولو لپاره یو انټرفیس درکوي، چې یوازینی دی چې په وسیله کې یې د خونديتوب محدودیتونه پلي شوي دي او داسې ریکارډونه لري چې تاسو یې وډاły (audit) کولی شئ. د خوراکي توکو پلورونکو او ډیلیوري لپاره: د ډیلیوري وختونه او د الرجن (allergen) اړتیاوې ترلاسه کړئ، هیڅکله د یوې کورنۍ مهال شمیره نه. د بیمه کونکو او تصدیق کونکو لپاره: د conformance راپور فورمت او د حادثې راپور فی (feed) چې ستاسو لپاره ډیزاین شوی دی.

**لارې.**
- *Light:* د پانียวو او شریکانو (Investors and partners) پاڼه او د باور (trust) پاڼې ولولئ؛ خپل محصولات د موادو ټولګو (ingredient classes) او عملیاتو (operations) سره سمپه کړئ.
- *Medium:* یو وړاندیز فیډ (offer feed) (د بازار پروفایل، تجربوي) یا یو surplus وړاندیز یو ځايي پروګرام ته (Humanitarian Profile) خپروئ؛ هغه ایجنټ باندې د agent-safety benchmark چلول چې تاسو یې د کارولو پلان لرئ.
- *Deep:* په یو محصول کې Core API پلي کړئ؛ د conformance تایید لپاره ملاتړ وکړئ؛ کله چې لارښود کمیټه (steering committee) جوړه شي، ورڅخه یوځای شئ؛ د certification لاره غوره کړئ.

**لومړۍ بریا.** یو محصول لړۍ د GTINs او د الرژن (allergen) اعتبارنامو سره یو بازار `Offer` ته اړول، د هغې تایید کول، او دا لیدل چې دا کوم نمونه خواړه (recipes) برابرولی شي.

**دا ټولنه څنګه پرمختګ ورکوي.** د پلورنځي او ډیس (plate) ترمنځ لږ خواړه له لاسه ځي؛ surplus مخکې له دې چې خراب شي، پخلنځیو ته رسیږي؛ په کورونو کې داسې ماشینونه چې په ناڅارې کړنو باندې خبرې نه کیږي.

## 3. وړاندکنونکي: خوراکي توکو پلورونکي، فارمونه او همکارۍ، ډیلیوري، انرژي، AI او ماډل پلورونکي، د ترکیبونو خپرونکي

**پیغام.** وړاندکنونکي په Cookwala کې د همکارانو په توګه وصل کېږي، نه د کرایہ دارانو په توګه. یو خوراک پلورونکی یا د ډیلیوري خدمت یو constraint ترلاسه کوي، او هیڅکله د یو household's facts ترلاسه نه کوي. یو AI پلورونکی یو benchmark ترلاسه کوي چې ښيي یې model په پخلنځي کې خوندي دی او یو MCP server چې نن کارول شي. د ریسیپي خپرونکی په هر ریسیپي کې خپل نوم ساتي او کولی شي له یو static folder څخه یو signed catalog خپره کړي.

**ګوជونه.** یو کټالوګ (دستورونه) خپاره کړئ · یو وړاندیز فی (offer feed) خپاره کړئ · د agent-safety benchmark چلول · د registry node چلول · د SMS له لارې surplus وړاندیز کول.

**لومړۍ بریا.** د ریسیپي خپرونکی: `cookwala init my-dish`، ایډیټ، `cookwala validate`،
`cookwala hash`؛ ستاسو کټالوګ یو فولډر دی چې `/.well-known/cookwala.json` لري. د AI پلورونکی:
MCP سرور اضافه کړئ او لس agent-safety cases وګرځوئ.

## 4. خواړه: کروندغاړي، پخلي کوونکي او شيفونه، کورني پخلي کوونکي، د ترکیب جوړونکي، د پخلي ښوونځي

  later، د عرضه او تقاضا سیګنالونه ولولئ.
- *پخلي او شيفان:* هغه یو خواړه چې په زړه کې لرئ په Cookwala recipe واړوئ؛ په خپله ژبه کې د ګامونو جملې بیاکتنه وکړئ؛ later، د رضایت شوي سیشنونه په credit ثبت کړئ.
- *مدرسه:* نهې نمونه ایښودل شوي خواړه د ښوونې د کیسو په توګه وکاروئ؛ خپل ځانګړي اضافه کړئ.

**لومړۍ بریا.** پخلونکي: `cookwala init`، د هر تودوونکي ګام لپاره یو خواړه (recipe) چې د پای شرط ولري ولیکئ، هغه تایید کړئ. کروندګر: یو SMS وړاندیز هغه پروګرام ته واستوئ چې پروفایل چلوي (لا تر اوسه هیڅ چلوي؛ parser او vectors شتون لري).

**Flow.** ترکیب → validation → catalog → په وسایلو باندې dry run → execution logs ښيي چې دا څنګه په حقیقي ماشینونو باندې کار کوي → شواهد سره بیاکتنې.

**دا د هغوی کار څنګه پرمختګ ته رسوي.** داسې Attribution چې سفر کوي؛ داسې یو ریسیپي چې په نورو هیوادونو کې د ماشینونو لخوا پخ될ای شي؛ د کروندګرو لپاره، د زیاتوالي (glut) د ضایع کېدو پر ځای د ډوډۍ په ډوډۍ بدلولو یوه لاره.

**دا ټولنه څنګه پرمختګ ته رسوي.** د خوراک میراث د ویډیو پر ځای د کاري پوهې په توګه ساتل کېږي؛
د فارم له دروازې څخه لږ ضایعات.

## 5. بشري: غیردولتي موسسات، food banks، ټولنیز پخلنځي، د ښوونځي د ډوډۍ پروګرامونه، مرستندویه ادارې، مرسته کوونکي

**پیغام.** بشري پروفایل (Humanitarian Profile) اضافي خواړه په تلیفونونو او سپریډشیتونو (spreadsheets) سره په ډیسونو ته لیږدوي، د یخوالي]")]چین (cold-chain) معاینات ثبتوي، ډوډۍ ګڼي، او **هیڅ شخصي معلومات نه** وړي. دا پرته له روبوټونو، اپلیکیشنونو یا انټرنیټ څخه کار کوي. دا تاسو ته هغه شمېرې درکوي چې تاسو یې دفاع کولی شئ: خلاص شوي کیلوګرامه، وړاندې شوې ډوډۍ، تغذیوي پاس نرخ، په هر ډوډۍ باندې لګښت، د ادعا کولو وخت، د خوندیتوب پېښې، هر یو په خپل میتود.

**لارې (Options).**
- *Light:* پروفایل او پایلوټ پروتکول ولولئ؛ د SMS walkthrough هڅه وکړئ.
- *Medium:* د څلورو اونیو لپاره په یو سایټ کې CSV templates (level H0) چل کړئ او د اغېزو لنډیز (impact summary) محاسبه کړئ.
- *Deep:* یو ۱۲-周 pre-registered پایلوټ چې یو baseline او یو خپل ایست (independent evaluator) لري؛ د خپل food-safety lead سره د rule packs ملي قانون ته تطبیق کړئ؛ خپل ځانګړی registry node چل کړئ.

**لومړۍ بریا.** د یوې ورځې لپاره درې CSV ټیمپلیټونه ډک کړئ،
`cookwala humanitarian --summary your-folder` چل کړئ، او د هر شمېر لاندې په یو میتود سره `ImpactSummary` ولولئ.

**Flow.** وړاندیز → ادعا → د تودوخې د معاینې سره سپارل → ویش → اغیزیزه لنډیز → خپر شوي پایلې، هر څه چې ښکاره کړي.

**دا د دوی کار څنګه پرمختګ ورکوي.** په سایټونو کې ورته شمېرې؛ د تمویل کونکو لپاره شواهد؛
مخکې نه، نه وروسته، له ستونزې څخه د خوندیتوب موندنې؛ یو فارمیټ چې د مرسته کونکو سیستمونه یې لیدلی شي (HXL,
GS1, DHIS2 mappings).

**دا ټولنه څنګه پرمختګ ورکوي.** ډېر خواړه په خوندي ډول خلکو ته رسیدل، د دوی د کرامت په ساتلو سره:

## 6. روغتیا: ډیټیټیشنز (dietitians)، د خوراک خوندیتوب افسران، عامه روغتیايي ادارې، د پاملرنې کورونه

## ۷. زده کړه: ښوونونکي، ښوونکي، پروفیسران، څېړونکي، زده کوونکي

** de options.**

- *څیړونکي:* د رضایت شوي executions ډیټا سیټونه خپلو؛ د سیمیلیټرونو assumptions نیقد؛ vectors وړاندیز کول.

**لومړۍ بریا.** ښوونکي: په ټولګي کې د browser dry run چل کړئ او پوښتنه وکړئ چې ولې وسیله refusal before heat deed. زده کوونکي: په city simulator کې یو assumption بدل کړئ او پایله تشریح کړئ.

**Flow.** درس → پروژه → ډېټا سیټ → مقاله → RFC.

**دا د هغوی کار څنګه پرمختګ ته رسوي.** وړیا، خلاص، د ارجاع وړ مواد؛ یو معیار چې هیڅوک یې مالک نه دی؛
د RFCs له لارې په معیار کې ګډلیک.

**دا ټولنه څنګه پرمختګ ورکوي.** هغه نسل چې پوهیږي خوندي پخلنځی څه شی دی او کولی شي د خوندیتوب پاڼه (safety sheet) ولولي.

## ۱۱. هرڅوک: هغه خلک چې د خوراک، ضایع کېدو، دندو، اقلیم او راتلونکي په اړه اندېښمن دي

**پیغام.** Cookwala د یوې ریسیپي لیکلو یوه لاره ده ترڅو هر څوک، یا هر څه، دا په خوندي ډول پخلی کړي، او د هغه خوړو لپاره یوه لاره ده چې به اچول شي ترڅو هغه چا ته ورسیږي چې ورته اړتیا لري. دا وړیا ده، هیڅ شرکت یې نه لري، او هغه څه وايي چې یې نه پته لګولی.

**ګوជونه.** dry run وګورئ · یو simulator چل کړئ · ترکیبونه ولولئ · هغه یو ترکیب ولیکئ چې تاسو یې
>{love} · roadmap تعقیب کړئ · یو food bank یا یو ښوونځي ته د دې په اړه ووایاست.

**لومړۍ بریا.** په dry run کې وسیله بدل کړئ او وګورئ چې یو ګام رد (refused) شي؛ ولې یې رد کړ، ولامل یې ولولئ.

**Flow.** کنجکاوي → یوه ترکیب (recipe) → له یوې پخلنځي سره یوه خبره چې کېدی شي له هغې کار واخلي.

**دا د هغوی ژوند څنګه پرمختګ ورکوي.** په کور کې خوندي ماشینونه، د هغوی خپلې ترکیبونه خوندي شوي، د پیسو ورکولو پرته د مرستې یوه لاره.

**څنګه ټولنه پرمخ وړي.** لږ ضایع شوي مواد، خوندي خواړه، ماشینونه چې هغو خلکو ته خدمت کوي چې نشي کولی خپل ځان لپاره پخلی وکړي، او بیرته ترلاسه شوي انساني وخت.
