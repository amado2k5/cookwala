# Μηνύματα: τι λέει το Cookwala, και πώς

**Status:** 2026-10-04. Γραμμένο πριν από τις σελίδες. Κάθε σελίδα ακολουθεί αυτό το έγγραφο.

## 1. Η μία πρόταση

**Η Cookwala είναι το ανοιχτό πρότυπο για ασφαλές μαγείρεμα: άνθρωποι, κουζίνες και ρομπότ.**

Αραβικά: **Cookwala είναι το ανοικτό πρότυπο για την ασφαλή μαγειρική: για ανθρώπους, κουζίνες και ρομπότ.**

## 2. Η τριάδα, που χρησιμοποιείται παντού

Μια συνταγή Cookwala λέει τρία πράγματα που ένα μηχάνημα μπορεί να ελέγξει:

1. **Τι να φτιάξει.** Συνταγές ως βήματα που ένα μηχάνημα μπορεί να σχεδιάσει.
2. **Πότε τελειώνει.** Θερμοκρασίες, ενδείξεις κατάστασης τροφίμων και χρόνοι που μπορεί να μετρήσει.
3. **Τι δεν πρέπει ποτέ να συμβεί.** Όρια ασφαλείας που η συσκευή επιβάλλει στον εαυτό της.

Αραβικά: **Τι μαγειρεύουμε. Πότε είναι έτοιμο. Τι δεν πρέπει ποτέ να συμβεί.**

## 3. Η αποστολή, ειλικρινά αφηγηθείσα

- **Αποστολή:** βοήθεια στον τερματισμό της πείνας, υγιέστεροι άνθρωποι και η αξιοποίηση των ρομπότ για το επίκρατο των ανθρώπων.
- **Πώς το λέμε:** "Η Cookwala βοηθά στον τερματισμό της πείνας μέσω…" ακολουθούμενο από έναν μηχανισμό (λιγότερη σπατάλη,
  ασφαλέστερη διάσωση, φθηνότερα γεύματα, συντονισμός), ποτέ "Η Cookwala τερματίζει την πείνα".
- **Η επισημάνωση, μία φορά ανά σελίδα όπου εμφανίζεται η αποστολή:** η πείνα έχει πολλές αιτίες: φτώχεια,
  σύγκρουση, κλίμα, τιμές, πολιτική. Το μέρος της Cookwala είναι πραγματικό και μερικό.

## 4. Τρεις ορίζοντες, με αυτοσυγκράτηση

| Ορίζοντας | Πείτε | Μην λέτε |
|---|---|---|
| Now (έως το 2028) | Πιο ασφαλείς συσκευές που κάνουν refusal rather than guess; συνταγές που λειτουργούν σε διάφορες μηχανές; food banks που σώζουν περισσότερα με τηλέφωνα και spreadsheets; agents που δεν μπορούν να εξαπατηθούν; ανοιχτά εργαλεία που μπορείτε να τρέξετε σήμερα | "widely adopted", "proven" |
| Next (2028 έως το 2036) | Οικιακοί και εμπορικοί robots που μαγειρεύουν κάθε κουζίνα; ένα consented dataset που κρατά τις συνταγές ζωντανές; νέοι ρόλοι; λιγότερη σπατάλη; φθηνότερα, πιο υγιεινά γεύματα; ένα πρότυπο στο οποίο αναφέρονται οι ρυθμιστές | "robots in every home", numbers of robots |
| Later (2036 και μετά) | Το μαγείρεμα ως υποδομή: θρεπτική τροφή για οποιονδήποτε, οπουδήποτε, συμπεριλαμβανομένων περιοχών καταστροφών και ανθρώπων που δεν μπορούν να μαγειρέψουν; λιγότερη σπατάλη και χαμηλότερες εκπομπές; επιστροφή του ανθρώπινου χρόνου; μηχανές που κληρονομούν την μαγειρική κληρονομιά αντί να την σβήνουν | dates, counts, "end hunger" |

Ο αναγνώστης ανακαλύπτει την κλίμακα ακολουθώντας τους μηχανισμούς· εμείς δεν την ανακοινώνουμε.

## 5. Συγγραφή κανόνων

- Απλά λόγια, σύντομες προτάσεις. Μία ιδέα ανά πρόταση.
- Χωρίς buzzwords: όχι revolutionary, disruptive, AI-powered, world-class, first and largest.
- Κάθε αριθμός είναι **measured**, **modelled** ή **assumed**, με την πηγή του, ορατή δίπλα στον αριθμό.
- **Now / next / later** για οτιδήποτε δεν υπάρχει ακόμα. Ποτέ μην υπονοείτε ότι μια υπηρεσία υπάρχει.
- Όχι συνεργάτες, χρήστες, πιλοτικές εφαρμογές, αποφθέγματα, λογότυπα ή υποστήριξη που δεν υπάρχουν. Οι οργανισμοί εμφανίζονται ως πηγές ή ως "αυτοί με whom θέλουμε να συνεργαστούμε", με την κατάλληλη σήμανση.
- Οι άνθρωποι περιγράφονται από τον ρόλο και την κατάστασή τους, ποτέ από την ελλείψή τους. Όχι "οι ευάλωτοι" ως ουσιαστικό· "παιδιά κάτω των πέντε ετών", "άνθρωποι που δεν μπορούν να μαγειρέψουν για τους ίδιους".
- Η ασφάλεια είναι ένας αριθμός με μια μονάδα, ποτέ μόνο η λέξη "safe".
- Η refusal είναι καλά νέα. Πείτε με υπερηφάνεια "το συσκευή κάνει refusal before heat".
- Πείτε τι δεν γνωρίζουμε και τι πήγε στραβά, σε κάθε σελίδα επιπτώσεων και οδικού χάρτη.
- Κώδικας σε code blocks; αναμενόμενη έξοδος μετά από κάθε εντολή.
- Τα Αραβικά είναι μια έκδοση πρώτης τάξης, όχι μια μετάγλώττιση: ίδια δομή, ίδια ειλικρίνεια, διάταξη δεξιά-αριστερά, αραβικοί αριθμοί όπως περιμένει ο αναγνώστης (οι δυτικοί αριθμοί είναι αποδεκτοί σε τεχνικό περιεχόμενο).

## 6. Λεξιλόγιο

## 7. Απόδειξη που μπορούμε να δείξουμε σήμερα

Καταμετρημένα από το repository κατά το build time (`/v1/stats.json`): λειτουργίες με φυσικές
ορισμούς, διανύσματα conformance, όρια ασφαλείας, δοκιμές agent-safety, ανθρωπιστικοί κανόνες,
schemas, δημοσιευμένες συνταγές, γλώσσες, simulators. Κάθε ένα δείχνει το είδος του. Τίποτα άλλο δεν είναι
αριθμός εκτός εάν παρατίθεται πηγή.

## 8. Κλήσεις σε δράση ανά ρήμα

δοκιμή (dry run, simulator) · ανάγνωση (quickstart, Core, whitepaper) · κατασκευή (SDK, hub, MCP) ·
δημοσίευση (recipe, device, pack) · πιλοτική εφαρμογή (humanitarian) · αναθεώρηση (rule pack, envelopes) ·
διδασκαλία (lesson kit) · νομοθεσία (model language) · συνεργασία και επένδυση (investors page) ·
συνεισφορά (RFC, translation, vectors).

## 9. Τράπεζα τίτλων

- Το ανοικτό πρότυπο για ασφαλές μαγείρεμα.
- Τι να φτιάξετε. Όταν είναι έτοιμο. Τι δεν πρέπει ποτέ να συμβεί.
- Συσκευές που αρνούνται αντί να μαντεύουν.
- Τρόφιμα που θα πετούσε κάποιος, φτάνοντας σε ένα πιάτο, με ασφάλεια, μέσω SMS.
- Κάθε κουζίνα, με το όνομα του μάγειρα πάνω της.
- Η ασφάλεια είναι τοπική. Η συγκατάθεση είναι ρητή. Τα αρχεία μπορούν να ελεγχθούν.
- Τα ρομπότ μαθαίνουν να κινούνται. Κανείς δεν είχε καταγράψει πώς να μαγειρεύει.
