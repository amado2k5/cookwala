# Κουζίνες και περιόди παραγωγής: εστιατόρια, κοινότητα, σχολείο, καταστροφή και ρομποτικές κουζίνες

> **Κατάσταση: experimental profile** (RFC-0005). Schema: `schemas/fleet.schema.json`.
> Παραδείγματα: `examples/fleet/`.

## 1. Γιατί

Ο ιδρυτής ζήτησε το ίδιο πρωτόκολλο σε ένα εστιατόριο, έναν γάμο, μια καμπάνια δωρεών ή ένα εργοστάσιο τροφίμων (RFC-0005). Η σύνοψη προσθέτει προγράμματα σχολικών γευμάτων και κουζίνες καταστροφών. Το Core καλύπτει μία συσκευή που μαγειρεύει μία συνταγή· το Humanitarian Profile καλύπτει τη μετακίνηση surplus και τον καταμέτρηση γευμάτων. Ανάμεσά τους βρίσκεται η **κουζίνα**: σταθμοί, συσκευές, άνθρωποι, πολλά batches, ένα παράθυρο σερβιρίσματος, κρίσιμα σημεία ελέγχου και ο σύνδεσμος από το execution log μιας συσκευής στα γεύματα που αναφέρει ένα πρόγραμμα.

## 2. Έγγραφα

| Έγγραφο | Τι λέει |
|---|---|
| `Kitchen` | Η κουζίνα ενός οργανισμού: τύπος, σταθμοί (προετοιμασία, εστία, φούρνος, τηγάνι, βραστήρας, κυτταρικό ρομποτικού συστήματος, σερβιρίσματος, συσκευασίας, διατήρησης σε θερμότητα, ψύξης, ψυγείου, πλύσης), συσκευές ως αναφορές ικανότητας, χωρητικότητα σε γεύματα ανά ώρα, εξοπλισμός διατήρησης σε θερμότητα και ψύξης, rule packs σε ισχύ, **αριθμός προσωπικού ανά ρόλο**, ώρες λειτουργίας |
| `ProductionRun` | Συνταγές με αριθμό παρτίδων και μερίδες, ένα παράθυρο σερβιρίσματος, αναθέσεις ανά βήμα συνταγής σε έναν σταθμό και σε ένα `device`, ένα `person` ή και τα δύο, καταγραφές κρίσιμων σημείων ελέγχου (πυρήνας θερμοκρασίας μαγειρέματος, διατήρηση σε θερμότητα, ψύξη δύο σταδίων, αναပρόθερμανση, ψυχρή αποθήκευση, διαχωρισμός αλλεργιογόνων), οι Core εκτελέσεις που παράχθηκαν, και ένα αποτέλεσμα (γεύματα που παράχθηκαν και σερβιρίστηκαν, απόβλητα, σωσεμένο φαγητό που χρησιμοποιήθηκε, αποτυχίες, περιστατικά, ενέργεια, κόστος, η ανθρωπιστική `Distribution` που εξέπεμψε) |
| `StationLease` | Αποκλειστική χρήση ενός σταθμού από ένα device ή έναν ρόλο για ένα χρονικό διάστημα |

## 3. Πώς συνδέεται με τα υπόλοιπα

- Ένα βήμα που ανατίθεται σε ένα `device` είναι ένα Core `ExecuteRequest` (ή ένας στόχος `ExecuteNode` μέσω του
  ROS 2 binding); το hash του `ExecutionLog` μπαίνει στο `executions`.
- Μια run που εξυπηρετεί ένα πρόγραμμα εκπέμπει ένα Humanitarian `Distribution`; τα `ccps` της run είναι τα
  evidence πίσω από τα findings ασφάλειας της διανομής.
- Τα rule packs από το Humanitarian Profile εφαρμόζονται στο μενού και τα items της run.
- Το fleet dispatch (ποιος robot πάει πού) ανήκει στο Open-RMF ή σε έναν fleet manager ενός προμηθευτή,
  όχι σε αυτό το profile.

## 4. Παράδειγμα με επεξεργασία

`examples/fleet/kitchen-disaster.json` και `production-run-disaster.json`: μια κουζίνα ανακούφισης
με δύο αερόθερμα, μονάδες διατήρησης θερμοκρασίας και ένα μπάνιο πάγου παράγει 710 γεύματα φακής και
ρύζι για ένα παράθυρο δύο ωρών, καταγράφει θερμοκρασίες μαγειρέματος και διατήρησης, εντοπίζει μία μονάδα διατήρησης
κάτω από 60 °C και αναθερμαίνει αυτή την παρτίδα πριν την σερβιρίσμα, και εκπέμπει μια διανομή. Το παράδειγμα είναι
εικονογραφικό· δεν περιγράφεται καμία πραγματική κουζίνα ή γεγονός.

## 5. Τι έχει παραλειφθεί σκόπιμα

Ονόματα προσωπικού και προγράμματα, μισθοί, παραγγελίες και πληρωμές πελατών, τιμολόγηση μενού. Το προσωπικό εμφανίζεται
ως αριθμοί ανά ρόλο, ώστε να μπορεί να υπολογιστεί το κόστος ανά γεύμα χωρίς να προσδιορίζεται κανείς.
