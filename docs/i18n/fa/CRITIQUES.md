# انتقادهایی که منتشر کردیم

ما سوالات دشواری درباره Cookwala پرسیدیم و پاسخ‌ها را یادداشت کردیم. هر نگرانی دارای یک id در [action plan's concern register](ACTION-PLAN.md#2-concern-register) است، به همراه پاسخ ما و وضعیت آن. بررسی‌های بیرونی خوشایند هستند و در اینجا فهرست خواهند شد.

## آیا این کار خواهد کرد؟ (strategy)

| نگرانی | پاسخ کوتاه | وضعیت |
|---|---|---|
| بازار هنوز وجود ندارد؛ مشخصات فنی جلوتر از محصولات است | Small Core، ابتدا دمو، بدون کاربران مشخصات فنی جدید نیست | Core 0.2 انجام شد؛ دمو دستگاه next |
| هیچ فرد قدرتمندی دلیلی برای پذیرش ندارد | پیشروی با سود هر پذیرنده؛ بدون ربات‌ها کاربردی است | جستجو برای pilot food-bank و شریک دستگاه |
| شبیه‌سازها آنچه را که assume می‌کنند اثبات می‌کنند | خط پایه منصفانه، محدوده‌ها، برچسب‌های "illustrative"؛ pilotها جایگزین آن‌ها می‌شوند | Open |
| گرسنگی مربوط به فقر و درگیری است، نه surplus | Cookwala کمک می‌کند؛ ادعا نمی‌کند که به تنهایی گرسنگی را پایان می‌دهد | پیام تغییر کرد |
| ایمنی، مسئولیت و سطح حمله | محدودیت‌ها روی دستگاه اعمال می‌شود؛ refusal؛ recallها؛ گزارش‌های حادثه | مشخصات فنی انجام شد؛ بررسی certifier open |
| حریم خصوصی (داده‌های سلامت و مذهب، دفترهای کل در مقابل پاکسازی) | اولویت با محلی بودن، افشای انتخابی، لاگ‌های فقط hash، رضایت | مشخصات فنی انجام شد؛ ارزیابی اثرگذاری open |
| بسیار پیچیده | Core 0.2؛ بقیه موارد به عنوان experimental علامت‌گذاری شده‌اند | Done |
| وابستگی به بنیان‌گذار | مسیر حکمرانی به سمت یک خانه بی‌طرف | GOVERNANCE.md |

## آیا طراحی فنی درست است؟

| نگرانی | چه چیزی در Core 0.2 تغییر کرد |
|---|---|
| عملیات‌ها معنای فیزیکی نداشتند | Envelopes، سطوح حرارتی، sensor ladders، قانون ارتفاع، بردارهای تست |
| باگ‌های واحد و عدد | فقط °C، تلرانس‌های مطلق، واحدهای آشپزخانه، چگالی‌ها، مبالغ اعشاری |
| طرحواره‌ها غلط‌های تایپی را می‌پذیرفتند | طرحواره‌های سخت‌گیرانه با افزونه‌های `x-`؛ باندل آفلاین |
| یک سند Mission تغییرپذیر | Event log + projection، یک سکوئنسر واحد، جدول گذارها |
| دفتر کل اطلاعات کمی ارائه می‌داد | سوابق کلیدی با ابطال، چک‌پوینت‌های شاهد شده، تشخیص بازنویسی |
| تحویل رویداد تعریف نشده؛ ایمنی در گذرگاه | شماره‌های توالی، کلاس‌های تأخیر، ضربان قلب، "ایمنی محلی است" |
| انحراف سطوح API | Core OpenAPI؛ هر ارجاع در CI بررسی می‌شود |
| فاقد تأییدکننده | کتابخانه مرجع و ۱۰۶ بردار conformance |

## بررسی‌هایی که ما درخواست می‌کنیم

W3C TAG (identity, JSON-LD), IETF SCITT (event-log transparency), دانشمندان علوم غذایی
(envelopes)، افسران ایمنی مواد غذایی و متخصصان تغذیه (rule packs)، یک حسابرسی امنیتی، یک
بازبینی حفاظت از داده‌ها، و تحلیل شکافِ یک تاییدکننده (certifier). برنامه
[external review program](ACTION-PLAN.md#5-external-review-program-sequenced) را ببینید.
