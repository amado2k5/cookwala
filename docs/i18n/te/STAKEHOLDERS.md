# స్టేక్‌హోల్డర్లు: ఒక సందేశం, ఎంపికలు, ఒక మొదటి విజయం మరియు అందరి కోసం ఒక ఫ్లో

**Status:** 2026-10-04. ప్రతి సమూహం కోసం: Cookwala వారికి ఎందుకు ముఖ్యమో, తేలికపాటి స్థాయి నుండి లోతైన స్థాయి వరకు పాల్గొనే మార్గాలు, 15 నిమిషాల లోపు మొదటి విజయం, దాని తర్వాత మార్గం, మరియు పాల్గొనడం వారి పనిని మరియు ప్రపంచాన్ని ఎలా ముందుకు తీసుకెళ్తుందో ఇక్కడ ఉంది. ఇక్కడ లేని ఏ భాగస్వామిని, వినియోగదారుని లేదా పైలట్‌ను ఇక్కడ పేర్కొనబడదు. ఏదైనా ప్లాన్ చేయబడిన చోట, next లేదా later అని ఉంటుంది.

ప్రతి వరుస వెనుక ఉన్న మూడు లక్ష్యాలు: ఆకలిని అంతం చేయడంలో సహాయపడటం, ప్రజలను ఆరోగ్యంగా ఉంచడం, ప్రజల కోసం రోబోలను పనిలో పెట్టడం.

## 1. బిల్డర్స్: డెవలపర్స్, రోబోట్ మరియు అప్లయన్స్ మేకర్స్, ఎంబెడెడ్ ఇంజనీర్స్, AI-ఏజెంట్ బిల్డర్స్, స్మార్ట్-హోమ్ మరియు ప్లాట్‌ఫామ్ డెవలపర్స్, ఓపెన్-సోర్స్ కంట్రిబ్యూటర్స్

**సందేశం.** రోబోలు మరియు ఉపకరణాలు కదలడం నేర్చుకుంటున్నాయి. చికెన్ ఎప్పుడు సురక్షితంగా ఉంటుంది, లేదా ఒక దశను ఎప్పుడు refuse చేయాలి, లేదా "simmer" అంటే ఏమిటి అనే విషయాలను యంత్రం తనిఖీ చేయగలిగే రూపంలో ఎవరూ వ్రాయలేదు. Cookwala ఆ పొర: యంత్రం ప్లాన్ చేయగలిగే రెసిపీలు, అది కొలవగలిగే end conditions, మరియు అది తనపై తాను అమలు చేసే safety limits. ఇది open, royalty-free, model-neutral మరియు device-neutral, మరియు మీరు ఈరోజు రన్ చేయగలిగే conformance suite తో వస్తుంది.

**Options.**
- *Light:* బ్రౌజర్ dry run రన్ చేయండి; Core 0.2 చదవండి (ఒక సాయంత్రం).
- *Medium:* `pip install -e sdk/python`, ఉదాహరణ రెసిపీల ప్రకారం మీ పరికరం యొక్క సామర్థ్యాలను dry-run చేయండి, conformance వెక్టర్లను రన్ చేయండి, reference hub ని ప్రారంభించండి.
- *Deep:* పరికరం లేదా hub పై Core API ని అమలు చేయండి, conformance రిపోర్టును ప్రచురించండి, directory లో మీ పరికరాన్ని జోడించండి, RFC ని ప్రతిపాదించండి, ROS 2 bridge node ని వ్రాయండి, agent-safety benchmark కి attack cases ని జోడించండి.

**మొదటి విజయం (15 నిమిషాల లోపు).**
```bash
git clone https://github.com/amado2k5/cookwala && cd cookwala && pip install -e sdk/python
cookwala dryrun examples/koshari.cookwala.json --device examples/capabilities/robot-arm.json
# refused: cw.op.boil, missing_capability (and later: no oil thermometer, no deep frying)
cookwala dryrun examples/koshari.cookwala.json --device examples/capabilities/robot-arm.json --human-present
cookwala conformance --report report.json          # 106 vectors; a signed-ready report
```

**Flow.** Dry run → reference hub కి వ్యతిరేకంగా Core API ని అమలు చేయండి → conformance పాస్ చేయండి →
నివేదికను ప్రచురించండి → పరికరాన్ని జాబితా చేయండి → అంగీకరించబడిన execution logs లు LeRobot datasets మరియు
OpenTelemetry traces లు అవుతాయి.

**ఇది వారి పనిని ఎలా ముందుకు తీసుకెళ్తుంది.** వంట కోసం ఒక ఉమ్మడి టాస్క్ డెఫినిషన్ మరియు సక్సెస్ టెస్ట్, దీనితో పాటు పోల్చడానికి ఒక పబ్లిక్ బెంచ్‌మార్క్; వాటిని వ్రాయకుండానే ప్రతి వంటకంలోనూ రెసిపీలు; రెగ్యులేటర్లు చదవగలిగే ఒక సేఫ్టీ స్టోరీ; సేల్స్ డాక్యుమెంట్‌గా కన్‌ఫార్మెన్స్ రిపోర్ట్‌లు; దీనిని అమలు చేసేవారే నియంత్రించే ఒక స్టాండర్డ్‌లో ఫస్ట్-మూవర్ స్థానం.

**ఇది సమాజాన్ని ఎలా అభివృద్ధి చేస్తుంది.** ఊహించే బదులు refusal చేసే యంత్రాల వల్ల తక్కువ వంటగది మంటలు మరియు ఆహార సంబంధిత వ్యాధులు; కొన్ని రకాల వంటకాలకు బదులుగా ప్రపంచవ్యాప్త వంటకాలను వారసత్వంగా పొందే యంత్రాలు.

## 2. కంపెనీలు: స్టార్టప్‌లు, ఎంటర్‌ప్రైజెస్, ఫుడ్ కంపెనీలు, గ్రాసర్లు మరియు డెలివరీ, రెస్టారెంట్లు మరియు ఫుడ్ సర్వీస్, ఇన్సూరర్లు, సర్టిఫైయర్లు, సేల్స్ మరియు పార్టనర్‌షిప్ టీమ్స్

**Message.** ఆహారాన్ని తాకే ప్రతి కంపెనీ రాబోయే కొన్ని సంవత్సరాలలో వంట యంత్రాలను మరియు AI agents ను కలుస్తుంది. Cookwala వీటన్నింటికీ మీకు ఒకే ఇంటర్‌ఫేస్‌ను అందిస్తుంది, పరికరంపై safety limits అమలు చేయబడిన మరియు మీరు audit చేయగల రికార్డులు ఉన్న ఏకైక ఇంటర్‌ఫేస్ ఇది. కిరాణాదారులు మరియు డెలివరీ కోసం: డెలివరీ విండోలు మరియు allergen requirements ని స్వీకరించండి, ఒక కుటుంబం యొక్క షెడ్యూల్‌ను కాదు. ఇన్సూరెన్స్ మరియు certifiers కోసం: మీ కోసం రూపొందించబడిన conformance report ఫార్మాట్ మరియు incident-report ఫీడ్.

**Options.**
- *Light:* Investors మరియు partners పేజీని మరియు trust పేజీలను చదవండి; మీ ఉత్పత్తులను ingredient classes మరియు operations కు మ్యాప్ చేయండి.
- *Medium:* ఒక offer feed (market profile, experimental) లేదా local program (Humanitarian Profile) కు surplus offer ను ప్రచురించండి; మీరు deploy చేయాలని ప్లాన్ చేస్తున్న agent పై agent-safety benchmark ను రన్ చేయండి.
- *Deep:* ఒక ఉత్పత్తిలో Core API ని implement చేయండి; conformance verification కు స్పాన్సర్ చేయండి; steering committee ఏర్పడినప్పుడు అందులో చేరండి; certification path ను స్వీకరించండి.

**మొదటి విజయం.** ఒక ఉత్పత్తి రేఖను GTINs మరియు అలర్జీన్ క్రెడెన్షియల్స్‌తో మార్కెట్ `Offer`గా మార్చండి, దానిని ధృవీకరించండి, మరియు అది ఏ ఉదాహరణ రెసిపీలను సరఫరా చేయగలదో చూడండి.

**Flow.** ఫీడ్ అందించండి → గృహాల నుండి derived constraints → మీ స్వంత checkout ద్వారా ఆర్డర్లు → fulfilment events → execution reports నుండి reputation (సమ్మతితో).

**ఇది వారి పనిని ఎలా ముందుకు తీసుకెళ్తుంది.** డజన్ల కొద్దీ vendor integrations కి బదులుగా ఒక neutral layer కి ప్రాప్యత; వ్యర్థాలను తగ్గించే demand signals (later, competition-law review తర్వాత); ఇన్సూరెన్స్ కంపెనీలు ధర నిర్ణయించగలిగే certification; భద్రత యొక్క public record.

**ఇది సమాజాన్ని ఎలా అభివృద్ధి చేస్తుంది.** స్టోర్ మరియు ప్లేట్ మధ్య తక్కువ ఆహారం వృథా అవుతుంది; కుళ్ళిపోకముందే surplus వంటగదులకు చేరుతుంది; ఇళ్లలో అసురక్షిత చర్యల కోసం ఒప్పించలేని యంత్రాలు ఉంటాయి.

## 3. ప్రొవైడర్లు: grocers, farms and cooperatives, delivery, energy, AI and model vendors, recipe publishers

**Message.** ప్రొవైడర్లు Cookwala లోకి టెనెంట్లుగా కాకుండా పీర్స్‌గా ప్లగ్ ఇన్ అవుతారు. ఒక గ్రాసర్ లేదా డెలివరీ సర్వీస్ ఒక constraint ని పొందుతుంది, కానీ ఒక household యొక్క facts ని ఎప్పుడూ పొందదు. ఒక AI వెండర్ తన model వంటగదిలో సురక్షితమని చూపే ఒక benchmark ని మరియు ఈరోజు ఉపయోగించడానికి ఒక MCP server ని పొందుతుంది. ఒక రెసిపీ పబ్లిషర్ ప్రతి రెసిపీపై తన పేరును ఉంచుకోగలరు మరియు ఒక static folder నుండి సైన్ చేసిన catalog ని పబ్లిష్ చేయగలరు.

**Options.** ఒక catalog (recipes) ప్రచురించండి · ఒక offer feed ప్రచురించండి · agent-safety benchmark రన్ చేయండి · ఒక registry node రన్ చేయండి · SMS ద్వారా surplus అందించండి.

**మొదటి విజయం.** Recipe publisher: `cookwala init my-dish`, edit, `cookwala validate`,
`cookwala hash`; మీ catalog అనేది `/.well-known/cookwala.json` ఉన్న ఒక folder. AI vendor:
MCP server ని జోడించి పది agent-safety cases లను run చేయండి.

**Flow.** Catalog లేదా feed → మీ proven namespace కింద registry entry → ఏదైనా తప్పు జరిగితే recall feed → ఫలితాల నుండి reputation.

**ఇది వారి పనిని ఎలా ముందుకు తీసుకెళ్తుంది.** ఒకే ఫార్మాట్ ద్వారా ప్రతి పరికరం మరియు ఏజెంట్‌ను చేరుకోండి;
సంతకం ద్వారా క్రెడిట్ మరియు ప్రావెనెన్స్; నిజాయితీగా పాస్ అయినప్పుడు మార్కెటింగ్ ఆస్తిగా ఉండే ఒక సేఫ్టీ బెంచ్‌మార్క్.

**ఇది సమాజాన్ని ఎలా ముందుకు నడిపిస్తుంది.** వంటకాలకు (Recipes) సంబంధం అలాగే ఉంటుంది; ప్రజల కోసం పనిచేసే ఏజెంట్లు నమ్మకానికి అర్హత పొందకముందే `measured` చేయబడతారు.

## 4. ఆహారం: రైతులు, వంట చేసేవారు మరియు చెఫ్‌లు, ఇంటి వంట చేసేవారు, రెసిపీ సృష్టికర్తలు, వంట పాఠశాలలు

**Message.** Cookwala కోసం వ్రాయబడిన ఒక రెసిపీ, దానిని వండే ప్రతి పరికరంలోనూ మీ పేరు మరియు మీ వంటక శైలిని సజీవంగా ఉంచుతుంది, యంత్రం ఎప్పుడూ వదిలివేయకూడదు అని వ్రాయబడిన దశలతో సహా. అధిక ఉత్పత్తి ఉన్న ఒక ఫామ్ SMS ద్వారా దానిని జాబితా చేయగలదు మరియు అదే రోజున వంటగదిని చేరుకోగలదు. ఒక క్యులీనరీ స్కూల్ తనను తాను తనిఖీ చేసుకునే ఫార్మాట్‌తో ఆహార భద్రతను బోధించగలదు.

**Options.**
- *Farmers:* `FARM 120KG TOMATO A BB0411` ను ఒక ప్రోగ్రామ్ యొక్క గేట్‌వేకి (ఎక్కడైతే ఒకటి ఉంటే);
  later, సరఫరా మరియు డిమాండ్ సంకేతాలను చదవండి.
- *Cooks and chefs:* మీకు బాగా తెలిసిన ఒక రెసిపీని Cookwala రెసిపీగా మార్చండి; మీ భాషలో ఉన్న
  step వాక్యాలను సమీక్షించండి; later, క్రెడిట్‌తో సమ్మతి పొందిన సెషన్‌లను రికార్డ్ చేయండి.
- *Schools:* తొమ్మిది ఉదాహరణ రెసిపీలను బోధనా సందర్భాలుగా ఉపయోగించండి; మీ స్వంత వాటిని జోడించండి.

**మొదటి విజయం.** Cooks: `cookwala init`, ప్రతి heat step కోసం ఒక end condition తో ఒక recipe రాయండి, దానిని validate చేయండి. Farmers: profile ని నడిపే program కి ఒక SMS offer పంపండి (ఇంకా ఏదీ run అవ్వలేదు; parser మరియు vectors ఉన్నాయి).

**Flow.** Recipe → validation → catalog → పరికరాలపై dry run → execution logs నిజమైన యంత్రాలపై అది ఎలా పనిచేస్తుందో చూపుతాయి → సాక్ష్యాలతో సవరణలు.

**ఇది వారి పనిని ఎలా ముందుకు తీసుకెళ్తుంది.** ప్రయాణించే అట్రిబ్యూషన్; ఇతర దేశాల్లో యంత్రాల ద్వారా వండినيمكنే ఒక రెసిపీ; రైతుల కోసం, మిగులును వ్యర్థం చేయకుండా భోజనంగా మార్చే ఒక మార్గం.

**ఇది సమాజాన్ని ఎలా ముందుకు తీసుకెళ్తుంది.** వంటల వారసత్వం వీడియోగా కాకుండా, పని చేసే జ్ఞానంగా భద్రపరచబడుతుంది;
తక్కువ ఫామ్-గేట్ వ్యర్థం.

## 5. మానవతా సేవలు: NGOs, food banks, కమ్యూనిటీ కిచెన్‌లు, స్కూల్-మీల్ ప్రోగ్రామ్‌లు, రిలీఫ్ ఏజెన్సీలు, దాతలు

**Message.** Humanitarian Profile ఫోన్లు మరియు స్ప్రెడ్‌షీట్‌లతో surplus ఆహారాన్ని ప్లేట్లకు చేరుస్తుంది, cold-chain తనిఖీలను రికార్డ్ చేస్తుంది, భోజనాలను లెక్కిస్తుంది మరియు **no personal data** కలిగి ఉంటుంది. ఇది రోబోలు, యాప్‌లు లేదా ఇంటర్నెట్ లేకుండా పనిచేస్తుంది. ఇది మీరు సమర్థించగల సంఖ్యలను మీకు అందిస్తుంది: రక్షించబడిన కిలోగ్రాములు, వడ్డించిన భోజనాలు, nutrition pass rate, భోజనం ధర, క్లెయిమ్ చేయడానికి పట్టే సమయం, safety incidents, ప్రతిదీ దాని పద్ధతితో.

**Options.**
- *Light:* ప్రొఫైల్ మరియు పైలట్ ప్రోటోకాల్‌ను చదవండి; SMS walkthrough ప్రయత్నించండి.
- *Medium:* ఒక సైట్‌లో నాలుగు వారాల పాటు CSV templates రన్ చేయండి (level H0) మరియు ఒక
  impact summaryని లెక్కించండి.
- *Deep:* baseline మరియు ఒక స్వతంత్ర evaluatorతో కూడిన 12-వారాల pre-registered pilot;
  మీ food-safety leadతో కలిసి rule packsలను జాతీయ చట్టానికి అనుగుణంగా మార్చండి; మీ స్వంత registry
  nodeను రన్ చేయండి.

**మొదటి విజయం.** ఒక రోజు కోసం మూడు CSV టెంప్లేట్‌లను నింపండి,
`cookwala humanitarian --summary your-folder` రన్ చేయండి, ప్రతి సంఖ్య కింద ఒక పద్ధతితో `ImpactSummary` ని చదవండి.

**Flow.** Offer → claim → handover with a temperature check → distribution → impact
summary → published results, whatever they show.

**ఇది వారి పనిని ఎలా ముందుకు తీసుకెళ్తుంది.** సైట్‌ల మధ్య పోల్చదగిన సంఖ్యలు; నిధులదాతల కోసం సాక్ష్యం; సమస్య వచ్చిన తర్వాత కాదు, ముందే భద్రతా ఫలితాలు; దాతల సిస్టమ్‌లు చదవగలిగే ఫార్మాట్ (HXL, GS1, DHIS2 mappings).

**ఇది సమాజాన్ని ఎలా ముందుకు నడిపిస్తుంది.** వారి గౌరవం దెబ్బతినకుండా, మరింత ఆహారం సురక్షితంగా ప్రజలకు చేరుతుంది:
పేర్లు లేవు, ముఖాలు లేవు, ప్రొఫైలింగ్ లేదు.

## 6. ఆరోగ్యం: dietitians, food-safety officers, public-health agencies, care homes

**సందేశం.** పబ్లిక్ గైడెన్స్ నుండి ఉద్భవించిన, మెనూలు మరియు హ్యాండోవర్లకు వర్తించబడే, యంత్రం ద్వారా తనిఖీ చేయగల ప్యాక్‌ల రూపంలో ఉన్న పోషకాహారం మరియు ఆహార-భద్రత నియమాలు, వీటిని వృత్తి మరియు ఫలితం ఆధారంగా మీ సమీక్షతో రికార్డ్ చేయబడింది. ఏదీ వైద్య సలహా కాదు; ప్యాక్‌లు చెప్పే దానికంటే మించి ఏదీ క్లెయిమ్ చేయబడదు.

**Options.** టెంప్లేట్‌తో ఒక pack ను సమీక్షించండి (రెండు గంటలు) · ఒక pack ను జాతీయ rules కు అనుగుణంగా మార్చండి ·
మీరు సేవ చేసే ప్రజల కోసం care rules ప్రతిపాదించండి · later, ప్రోగ్రామ్‌ల నుండి aggregate outcomes చదవండి.

**మొదటి విజయం.** `profiles/humanitarian/care-vulnerable-groups.rulepack.json` మరియు
రివ్యూ టెంప్లేట్‌ను తెరవండి; మూడు రూల్స్‌ను approved, changed లేదా rejected గా మార్క్ చేయండి; రివ్యూను ఫైల్ చేయండి.

**Flow.** Draft pack → review → status reviewed → programs adopt → findings in every
distribution → outcomes published with methods.

**ఇది వారి పనిని ఎలా ముందుకు తీసుకెళ్తుంది.** రోబోట్ కిచెన్‌లతో సహా దీనిని స్వీకరించే ప్రతి వంటగదిలోనూ మీ మార్గదర్శకత్వం కొనసాగుతుంది, అందులో మీ వృత్తి రికార్డు చేయబడుతుంది; ఒక ప్రచురించదగిన సమీక్ష; పరిశోధన కోసం (సంగ్రహించినది, వ్యక్తిగత డేటా లేదు) ఫలితాల యొక్క dataset.

**ఇది సమాజాన్ని ఎలా అభివృద్ధి చేస్తుంది.** భారీగా అందించే భోజనంలో తక్కువ సోడియం, చక్కెర మరియు సంతృప్త కొవ్వు; సురక్షితమైన hot-holding మరియు cooling; పిల్లలు మరియు వృద్ధుల సంరక్షణ యంత్రంలోనే వ్రాయబడింది.

## 7. విద్య: పాఠశాల ఉపాధ్యాయులు, విద్యావేత్తలు, ప్రొఫెసర్లు, పరిశోధకులు, విద్యార్థులు

**Message.** వంట చేయడం అనేది ప్రపంచంలో అత్యంత పరిచయమున్న ప్రక్రియ, మరియు Cookwala దానిని ఒక బోధనా వస్తువుగా మారుస్తుంది: ఉష్ణోగ్రతలు, యూనిట్లు, సమానమైన పంపిణీ, భద్రత, నియమాలను అనుసరించే యంత్రాలు. పరిశోధకులకు ఇది ఒక benchmark, ఒక dataset format మరియు open-problems list.

**Options.**
- *Teachers:* పాఠం కిట్ (`docs/education/LESSON-KIT.md`): "what is a
  simmer" నుండి "what should a machine never do" వరకు ఐదు పాఠాలు.
- *Professors and students:* పరిశోధన అంశాల జాబితా, సిమ్యులేటర్లు, పరీక్షా పరిస్థితులుగా conformance
  vectors, LeRobot ఎగుమతి, థీసిస్-పరిమాణపు open problems.
- *Researchers:* సమ్మతి పొందిన executions యొక్క datasets ను ప్రచురించండి; సిమ్యులేటర్ల
  assumptions ను విమర్శించండి; vectors ను ప్రతిపాదించండి.

**మొదటి విజయం.** ఉపాధ్యాయులు: తరగతిలో బ్రౌజర్ dry run నిర్వహించి పరికరం ఎందుకు refusal చూపిందో అడగండి. విద్యార్థులు: సిటీ సిమ్యులేటర్‌లో ఒక assumption మార్చి ఫలితాన్ని వివరించండి.

**ప్రవాహం (Flow).** Lesson → project → dataset → paper → RFC.

**ఇది వారి పనిని ఎలా ముందుకు తీసుకెళ్తుంది.** ఉచిత, ఓపెన్, ఉదహరించదగిన మెటీరియల్; ఎవరికీ సొంతం కాని ఒక benchmark;
RFCs ద్వారా ప్రమాణంపై co-authorship.

**ఇది సమాజాన్ని ఎలా ముందుకు నడిపిస్తుంది.** సురక్షితమైన వంటగది అంటే ఏమిటో తెలిసిన మరియు భద్రతా పత్రాన్ని (safety sheet) చదవగలిగే ఒక తరం.

## 8. ప్రభుత్వం: ప్రభుత్వాలు, మంత్రిత్వ శాఖలు, నగర అధికారులు, నియంత్రణ సంస్థలు, రాజకీయ నాయకులు మరియు శాసనసభ్యులు, పాలనా మరియు ప్రమాణ సంస్థలు

**Message.** గృహ మరియు వాణిజ్య వంట యంత్రాలు ఉపకరణాలు మరియు సాఫ్ట్‌వేర్ కోసం విడివిడిగా వ్రాయబడిన నిబంధనల కింద వస్తున్నాయి. Cookwala నియంత్రణకర్తలకు సూచించడానికి ఒక స్పష్టమైన అంశాన్ని ఇస్తుంది: పరికరంపై అమలు చేయబడే భద్రతా పరిమితులు, refusal before heat, సంతకం చేయబడిన రికార్డులు, అజ్ఞాత ఇన్సిడెంట్ రిపోర్టింగ్, మరియు ఎవరైనా రన్ చేయగల conformance సూట్. ఆహార విరాళం భద్రత కోసం ఇది ఎటువంటి వ్యక్తిగత డేటా లేని డేటా ప్రమాణాన్ని అందిస్తుంది. ఇది రాయల్టీ-ఫ్రీ మరియు తటస్థ గవర్నెన్స్ వైపు వెళ్తోంది.

**Options.** పాలసీ బ్రీఫ్ (`docs/policy/BRIEF.md`) చదవండి · food-donation డేటా మరియు cooking-machine భద్రత కోసం మోడల్ లాంగ్వేజ్‌ని ఉపయోగించండి · మీ స్టాండర్డ్స్ బాడీని Core 0.2 రివ్యూ చేయమని కోరండి · నేషనల్ registry నోడ్‌ని రన్ చేయండి · మీ స్కూల్-మీల్ ప్రోగ్రామ్‌తో పైలట్‌కు నిధులు సమకూర్చండి.

**మొదటి విజయం.** రెండు పేజీల బ్రీఫ్ చదవండి మరియు రిపోజిటరీలో మూడు విషయాలను తనిఖీ చేయండి:
safety limits pack, conformance runner, మానవతా డేటా-రక్షణ నియమాలు.

**ప్రవాహం.** క్లుప్తమైనది → జాతీయ ప్రమాణాల సంస్థ ద్వారా సమీక్ష → మార్గదర్శకంలో సూచన → పైలట్ →
certification పథకం.

**ఇది వారి పనిని ఎలా ముందుకు తీసుకెళ్తుంది.** ఒక సిద్ధంగా ఉన్న, సమీక్షించదగిన సాంకేతిక ప్రాతిపదిక; పైలట్ల నుండి సాక్ష్యం; ఒక తటస్థ ప్రమాణం ద్వారా పరిశ్రమకు ఒక ఛానెల్; మీరు ఇప్పటికే ఉపయోగిస్తున్న మానవతా డేటా ప్రమాణాలతో పరస్పర అనుకూలత (interoperability).

**ఇది సమాజాన్ని ఎలా అభివృద్ధి చేస్తుంది.** ఇళ్లలో సురక్షితమైన యంత్రాలు; ఇది సేవ చేసే ప్రజలను రక్షించే ఆహార రక్షణ (food rescue); నగరాల్లో తక్కువ వ్యర్థాలు.

## 9. మూలధనం: పెట్టుబడిదారులు, పారిశ్రామికవేత్తలు,on పరోపకారిణులు, అభివృద్ధి బ్యాంకులు

**Message.** వంట చేయడం అనేది మౌలిక సదుపాయంగా మారబోతోంది. ప్రమాణం (standard) ఉచితం; దాని చుట్టూ ఉన్న సేవలు ఒక వ్యాపారం: certification, hub software, అంగీకరించబడిన datasets, registry operations, pilots. మానవతా దృక్పథం కలిగిన పొర (humanitarian layer) అనేది ఒక ప్రజా ప్రయోజనం, దీనిని అభివృద్ధి నిధులదారులు ముందుగా నమోదు చేయబడిన మూల్యాంకనం (pre-registered evaluation) తో సమర్థించగలరు. ఈ సైట్‌లో ఎక్కడా ఎటువంటి ఆర్థిక వాగ్దానాలు చేయబడలేదు.

**Options.** అవకాశం, బిజినెస్ మోడల్, రోడ్‌మ్యాప్, రిస్క్‌లు మరియు గవర్నెన్స్‌ను చదవండి
(`/investors`) · పైలట్ లేదా రివ్యూ కోసం నిధులు సమకూర్చండి · ఉచిత స్టాండర్డ్ పక్కన సేవలను విక్రయించే కంపెనీకి మద్దతు ఇవ్వండి · ఫండర్ అబ్జర్వర్‌గా గవర్నెన్స్‌లో చేరండి.

**మొదటి విజయం.** వైట్‌పేపర్ యొక్క problem, architecture మరియు risks విభాగాలు మరియు action plan యొక్క concern register ని చదవండి; ప్రతి open risk జాబితా చేయబడింది.

**Flow.** సాక్ష్యం (pilots, conformance, adopters) → action plan లోని gates → gates కు అనుసంధానించబడిన funding → standard కోసం neutral foundation, సేవలకు ఒక company.

**ఇది వారి పనిని ఎలా ముందుకు తీసుకెళ్తుంది.** నిజాయితీతో కూడిన నంబర్లతో, ఒక కేటగిరీని నిర్వచించే ప్రమాణంలో ముందస్తు స్థానం; ప్రజా ప్రయోజనం నుండి వేరు చేయబడిన ఒక పెట్టుబడి పెట్టదగిన సేవల సంస్థ.

**ఇది సమాజాన్ని ఎలా ముందుకు తీసుకెళ్తుంది.** పెట్టుబడి అనేది ఏమిటి అని క్లెయిమ్ చేయబడిందో దానికి కాకుండా, ఏమి అయితే measured చేయబడిందో దానికి వెళుతుంది.

## 10. ఆలోచన: తత్వవేత్తలు, నీతివేత్తలు, చరిత్రకారులు మరియు భవిష్యత్తువేత్తలు

**Message.** ఒక యంత్రం అమ్మమ్మ వంటకాలను వండినప్పుడు, ఆ జ్ఞానాన్ని ఎవరు కలిగి ఉంటారు? స్వయంచాలక సంరక్షణలో (automated care) గౌరవం అంటే ఏమిటి? ఒక household యొక్క రోబోట్ ఏమి తెలుసుకోగలదు, మరియు ఇంకెవరు దానిని తెలుసుకోగలరు? Cookwala ఈ ప్రశ్నల గురించి కోడ్‌లో నిర్ణయాలు తీసుకుంది; ఆ వ్యాసాలు (`docs/essays/`) అవి ఏమిటో చెబుతాయి మరియు విభేదించడానికి ఆహ్వానిస్తాయి.

**Options.** వ్యాసాలను చదవండి · ప్రతిస్పందనను వ్రాయండి · ఒక rule ని ప్రతిపాదించండి (an RFC అనేది ఒక schema తో కూడిన తాత్విక వాదన) · household context profile యొక్క ethics review లో కూర్చోండి.

**మొదటి విజయం.** household data మరియు facet registry యొక్క travel rules పై వ్యాసాన్ని చదవండి;
మీరు దాని default మార్చాలనుకునే ఒక facet ను కనుగొనండి, మరియు ఎందుకు అనేది చెప్పండి.

**ప్రవాహం (Flow).** వ్యాసం (Essay) → పబ్లిక్ కామెంట్ (public comment) → RFC → మారిన డిఫాల్ట్ (changed default).

**ఇది వారి పనిని ఎలా ముందుకు తీసుకెళ్తుంది.** నైతిక స్థానాలు అమలులో ఉన్న నియమాలుగా మారే ఒక ప్రత్యక్ష సందర్భం, దీనికి వాదన యొక్క బహిరంగ రికార్డు ఉంటుంది.

**ఇది సమాజాన్ని ఎలా ముందుకు నడిపిస్తుంది.** యంత్రాలు మిలియన్ల కొద్దీ ఇళ్లకు చేరువయ్యే ముందు, అత్యంత వ్యక్తిగత డేటా మరియు సాంస్కృతిక వారసత్వం గురించి బహిరంగంగా తీసుకోబడే నిర్ణయాలు.

## 11. అందరూ: ఆహారం, వ్యర్థాలు, ఉద్యోగాలు, వాతావరణం మరియు భవిష్యత్తు గురించి ఆందోళన చెందే ప్రజలు

**Message.** Cookwala అనేది ఒక రెసిపీని వ్రాయడానికి ఒక మార్గం, తద్వారా ఎవరైనా, లేదా ఏదైనా దానిని సురక్షితంగా వండుతుంది, మరియు పారవేయబడే ఆహారం అవసరమైన వ్యక్తికి చేరువ కావడానికి ఒక మార్గం. ఇది ఉచితం, ఇది ఏ కంపెనీకి చెందినది కాదు, మరియు దీనికి ఏమి తెలియదో ఇది చెబుతుంది.

**Options.** dry run ప్రయత్నించండి · ఒక simulator ఆడండి · వంటకాలను చదవండి · మీకు నచ్చిన ఒక వంటకాన్ని రాయండి · roadmap అనుసరించండి · ఒక food bank లేదా పాఠశాలకు దాని గురించి చెప్పండి.

**మొదటి విజయం.** dry run లో పరికరాన్ని మార్చండి మరియు ఒక దశ నిరాకరించబడడాన్ని గమనించండి; ఎందుకు అనేది చదవండి.

**ప్రవాహం.** Curiosity → ఒక రెసిపీ → దానిని ఉపయోగించుకోగల కిచెన్‌తో ఒక సంభాషణ.

**ఇది వారి జీవితాన్ని ఎలా మెరుగుపరుస్తుంది.** ఇంట్లో సురక్షితమైన యంత్రాలు, వారి స్వంత వంటకాలు భద్రపరచబడటం, డబ్బు ఇవ్వకుండా సహాయం చేసే మార్గం.

**ఇది సమాజాన్ని ఎలా అభివృద్ధి చేస్తుంది.** తక్కువ వ్యర్థం, సురక్షితమైన ఆహారం, తమ కోసం తాము వండుకోలేని వారికి సేవ చేసే యంత్రాలు, మరియు తిరిగి పొందిన మానవ సమయం.

## 12. ఉద్యోగాలు మరియు గౌరవం, స్పష్టంగా చెప్పబడినవి

వంట యంత్రాలు పనిని మారుస్తాయి. Cookwala యొక్క స్థానాలు: మనుషులు ఎల్లప్పుడూ వంట చేయగలరు; మొదటి ఉపయోగాలు తమ కోసం తాము వంట చేసుకోలేని వ్యక్తుల కోసం మరియు పనివారు తక్కువగా ఉన్న కమ్యూనిటీ కిచెన్‌ల కోసం; వంటకం ఎక్కడ వండినా వంట చేసే వ్యక్తి పేరు దానిపై ఉంటుంది; స్టీరింగ్ కమిటీలో ఒక కార్మిక స్వరం ఉంటుంది; కొత్త పాత్రలు (recipe engineers, food-robot technicians, certifiers, rule-pack reviewers) సంఖ్యలను వాగ్దానం చేయకుండా పేర్కొనబడతాయి.
