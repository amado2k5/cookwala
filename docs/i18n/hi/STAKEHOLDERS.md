# हितधारक: एक संदेश, विकल्प, एक पहली सफलता और सभी के लिए एक प्रवाह

**Status:** 2026-10-04. प्रत्येक समूह के लिए: Cookwala उनके लिए क्यों महत्वपूर्ण है, हल्के से गहरे स्तर तक जुड़ने के तरीके, 15 मिनट से कम में पहली सफलता, उसके बाद का मार्ग, और कैसे जुड़ना उनके काम और दुनिया को आगे बढ़ाता है। यहाँ किसी भी ऐसे भागीदार, उपयोगकर्ता या पायलट का नाम नहीं है जो अस्तित्व में नहीं है। जहाँ कुछ नियोजित है, वहाँ next या later लिखा है।

प्रत्येक पंक्ति के पीछे तीन लक्ष्य: भूख मिटाने में मदद करना, लोगों को अधिक स्वस्थ बनाना, लोगों के लिए रोबोट को काम पर लगाना।

## 1. बिल्डर्स: डेवलपर्स, रोबोट और उपकरण निर्माता, एम्बेडेड इंजीनियर, AI-agent बिल्डर्स, स्मार्ट-होम और प्लेटफॉर्म डेवलपर्स, ओपन-सोर्स योगदानकर्ता

**संदेश।** रोबोट और उपकरण चलना सीख रहे हैं। किसी ने भी, उस रूप में जिसे मशीन जांच सके, यह नहीं लिखा है कि "simmer" का क्या अर्थ है, कब चिकन सुरक्षित है, या कब किसी चरण को refuse करना चाहिए। Cookwala वह layer है: रेसिपी जिसे मशीन plan कर सकती है, end conditions जिन्हें वह measure कर सकती है, और safety limits जिन्हें वह स्वयं पर लागू करती है। यह open, royalty-free, model-neutral और device-neutral है, और यह एक conformance suite के साथ आता है जिसे आप आज चला सकते हैं।

**विकल्प।**
- *Light:* ब्राउज़र का dry run चलाएं; Core 0.2 पढ़ें (एक शाम)।
- *Medium:* `pip install -e sdk/python` चलाएं, उदाहरण रेसिपी के विरुद्ध अपने डिवाइस की क्षमताओं का dry-run करें, conformance vectors चलाएं, reference hub शुरू करें।
- *Deep:* किसी डिवाइस या hub पर Core API लागू करें, conformance रिपोर्ट प्रकाशित करें, अपने डिवाइस को directory में जोड़ें, एक RFC प्रस्तावित करें, एक ROS 2 bridge node लिखें, agent-safety benchmark में attack cases जोड़ें।

**पहली सफलता (15 मिनट से कम में)।**
```bash
git clone https://github.com/amado2k5/cookwala && cd cookwala && pip install -e sdk/python
cookwala dryrun examples/koshari.cookwala.json --device examples/capabilities/robot-arm.json
# refused: cw.op.boil, missing_capability (and later: no oil thermometer, no deep frying)
cookwala dryrun examples/koshari.cookwala.json --device examples/capabilities/robot-arm.json --human-present
cookwala conformance --report report.json          # 106 vectors; a signed-ready report
```

**प्रवाह।** Dry run → reference hub के विरुद्ध Core API लागू करें → conformance पास करें →
रिपोर्ट प्रकाशित करें → डिवाइस को सूचीबद्ध करें → सहमत execution logs, LeRobot datasets और
OpenTelemetry traces बन जाते हैं।

**यह उनके काम को कैसे आगे बढ़ाता है।** खाना पकाने के लिए एक साझा कार्य परिभाषा और सफलता परीक्षण, जिसके विरुद्ध मापने के लिए एक सार्वजनिक बेंचमार्क हो; उन्हें लिखे बिना हर व्यंजन में रेसिपी; एक सुरक्षा कहानी जिसे नियामक पढ़ सकें; बिक्री दस्तावेज़ के रूप में conformance रिपोर्ट; एक मानक में प्रथम-प्रवर्तक स्थिति जिसे इसके कार्यान्वयनकर्ताओं द्वारा शासित किया जाएगा।

**यह समाज को कैसे आगे बढ़ाता है।** उन मशीनों से रसोई की आग और खाद्यजनित बीमारियों में कमी आती है जो अनुमान लगाने के बजाय refusal करती हैं; ऐसी मशीनें जो कुछ चुनिंदा व्यंजनों के बजाय दुनिया के व्यंजनों को inherit करती हैं।

## 2. कंपनियाँ: स्टार्टअप्स, उद्यम, खाद्य कंपनियाँ, किराना और डिलीवरी, रेस्तरां और खाद्य सेवा, बीमाकर्ता, प्रमाणनकर्ता, बिक्री और साझेदारी टीमें

**Message.** हर कंपनी जो भोजन से जुड़ी है, वह अगले कुछ वर्षों में कुकिंग मशीनों और AI agents से मिलेगी। Cookwala आपको उन सभी के लिए एक इंटरफ़ेस देता है, जो डिवाइस पर लागू सुरक्षा सीमाओं और ऑडिट किए जा सकने वाले रिकॉर्ड के साथ एकमात्र है। ग्रोसर्स और डिलीवरी के लिए: डिलीवरी विंडो और एलर्जेन आवश्यकताएं प्राप्त करें, कभी भी किसी परिवार का शेड्यूल नहीं। बीमाकर्ताओं और certifiers के लिए: एक conformance रिपोर्ट फॉर्मेट और आपके लिए डिज़ाइन किया गया एक incident-report फीड।

**विकल्प।**
- *Light:* Investors and partners पेज और trust पेज पढ़ें; अपने उत्पादों को ingredient classes और operations के साथ मैप करें।
- *Medium:* एक offer feed (market profile, experimental) या किसी स्थानीय program (Humanitarian Profile) को surplus offer प्रकाशित करें; उस agent पर agent-safety benchmark चलाएं जिसे आप deploy करने की योजना बना रहे हैं।
- *Deep:* किसी उत्पाद में Core API लागू करें; conformance verification को प्रायोजित करें; steering committee के बनने पर उसमें शामिल हों; certification path अपनाएं।

**पहली सफलता।** एक उत्पाद लाइन को GTINs और एलर्जन क्रेडेंशियल्स के साथ मार्केट `Offer` में बदलें, इसे मान्य करें, और देखें कि यह किन उदाहरण रेसिपीज़ की आपूर्ति कर सकता है।

**प्रवाह।** Feed प्रदान करें → households से derived constraints → अपने स्वयं के checkout के माध्यम से orders → fulfilment events → execution reports से reputation (सहमति के साथ)।

**यह उनके काम को कैसे आगे बढ़ाता है।** दर्जनों वेंडर एकीकरण के बजाय एक तटस्थ परत तक पहुंच; मांग संकेत (later, प्रतिस्पर्धा-कानून समीक्षा के बाद) जो बर्बादी को कम करते हैं; certification जिसे बीमाकर्ता मूल्य निर्धारित कर सकते हैं; सुरक्षा का एक सार्वजनिक रिकॉर्ड।

**यह समाज को कैसे आगे बढ़ाता है।** स्टोर और प्लेट के बीच कम भोजन की बर्बादी; सड़ने से पहले surplus का रसोई तक पहुँचना; घरों में ऐसी मशीनें जिन्हें असुरक्षित कार्यों के लिए मनाया नहीं जा सकता।

## 3. प्रदाता: grocers, farms and cooperatives, delivery, energy, AI and model vendors, recipe publishers

**Message.** प्रदाता Cookwala में साथियों के रूप में जुड़ते हैं, किरायेदारों के रूप में नहीं। एक किराना स्टोर या डिलीवरी सेवा को एक constraint मिलता है, किसी household के facts कभी नहीं। एक AI vendor को एक benchmark मिलता है जो दिखाता है कि उसका model रसोई में सुरक्षित है और आज उपयोग करने के लिए एक MCP server मिलता है। एक recipe publisher हर recipe पर अपना नाम रखता है और एक static folder से एक signed catalog प्रकाशित कर सकता है।

**विकल्प।** एक कैटलॉग (recipes) प्रकाशित करें · एक offer feed प्रकाशित करें · agent-safety benchmark चलाएं · एक registry node चलाएं · SMS द्वारा surplus पेश करें।

**पहली सफलता।** रेसिपी पब्लिशर: `cookwala init my-dish`, एडिट, `cookwala validate`,
`cookwala hash`; आपका कैटलॉग `/.well-known/cookwala.json` वाला एक फोल्डर है। AI वेंडर:
MCP सर्वर जोड़ें और दस agent-safety cases चलाएं।

**Flow.** Catalog या feed → आपके proven namespace के तहत registry entry → यदि कुछ गलत हो जाए तो recall feed → परिणामों से reputation।

**यह उनके काम को कैसे आगे बढ़ाता है।** एक ही फॉर्मेट के माध्यम से प्रत्येक डिवाइस और एजेंट तक पहुँचें;
सिग्नेचर द्वारा क्रेडिट और प्रोवेनेंस; एक सुरक्षा बेंचमार्क जो ईमानदारी से पास होने पर एक मार्केटिंग एसेट बन जाता है।

**यह समाज को कैसे आगे बढ़ाता है।** रेसिपीज़ का श्रेय बना रहता है; जो एजेंट लोगों के लिए कार्य करते हैं, उन्हें भरोसा करने से पहले measured किया जाता है।

## 4. भोजन: किसान, रसोइए और शेफ, घरेलू रसोइए, रेसिपी निर्माता, पाक विद्यालय

**Message.** Cookwala के लिए लिखी गई एक रेसिपी आपके नाम और आपके व्यंजन को हर उस डिवाइस पर जीवित रखती है जो इसे पकाता है, जिसमें वे चरण लिखे होते हैं जिन्हें मशीन को कभी नहीं छोड़ना चाहिए। अधिकता वाले एक फार्म इसे SMS द्वारा सूचीबद्ध कर सकता है और उसी दिन रसोई तक पहुँच सकता है। एक पाक विद्यालय ऐसे प्रारूप के साथ खाद्य सुरक्षा सिखा सकता है जो स्वयं की जाँच करता है।

**विकल्प।**
- *किसान:* `FARM 120KG TOMATO A BB0411` को किसी प्रोग्राम के गेटवे (जहाँ उपलब्ध हो) पर;
  later, आपूर्ति और मांग के संकेतों को पढ़ें।
- *रसोइये और शेफ:* अपने मन में बसी किसी एक रेसिपी को Cookwala रेसिपी में बदलें; अपनी भाषा में
  चरण वाक्यों की समीक्षा करें; later, क्रेडिट के साथ सहमति प्राप्त सत्रों को रिकॉर्ड करें।
- *स्कूल:* नौ उदाहरण रेसिपी का शिक्षण मामलों के रूप में उपयोग करें; अपनी स्वयं की रेसिपी जोड़ें।

**पहली सफलता।** Cooks: `cookwala init`, प्रत्येक heat step के लिए एक end condition के साथ एक recipe लिखें, इसे validate करें। Farmers: उस program को एक SMS offer भेजें जो profile चलाता है (अभी तक कोई नहीं चलता; parser और vectors मौजूद हैं)।

**प्रवाह।** Recipe → validation → catalog → devices पर dry run → execution logs दिखाते हैं कि यह real machines पर कैसे perform करता है → evidence के साथ revisions।

**यह उनके काम को कैसे आगे बढ़ाता है।** ऐसा एट्रिब्यूशन जो यात्रा करता है; एक रेसिपी जिसे अन्य देशों में मशीनों द्वारा पकाया जा सकता है; किसानों के लिए, अधिशेष को कचरे के बजाय भोजन में बदलने का एक तरीका।

**यह समाज को कैसे आगे बढ़ाता है।** पाक विरासत को वीडियो के रूप में नहीं, बल्कि कार्यशील ज्ञान के रूप में संरक्षित किया जाता है;
कम farm-gate अपशिष्ट।

## 5. मानवीय: NGOs, food banks, सामुदायिक रसोई, स्कूल-भोजन कार्यक्रम, राहत एजेंसियां, दाता

**Message.** Humanitarian Profile फोन और स्प्रेडशीट्स के साथ surplus भोजन को थालियों तक पहुँचाता है, cold-chain जाँचों को रिकॉर्ड करता है, भोजन की गिनती करता है, और **कोई व्यक्तिगत डेटा नहीं** रखता है। यह रोबोट, ऐप्स या इंटरनेट के बिना काम करता है। यह आपको ऐसे नंबर देता है जिनका आप बचाव कर सकते हैं: बचाए गए किलोग्राम, परोसे गए भोजन, पोषण पास दर, प्रति भोजन लागत, दावा करने का समय, सुरक्षा घटनाएँ, प्रत्येक अपने तरीके के साथ।

**विकल्प।**
- *Light:* प्रोफाइल और पायलट प्रोटोकॉल को पढ़ें; SMS walkthrough आज़माएँ।
- *Medium:* चार सप्ताह के लिए एक साइट में CSV templates चलाएँ (स्तर H0) और एक
  impact summary की गणना करें।
- *Deep:* एक baseline और एक स्वतंत्र evaluator के साथ 12-सप्ताह का pre-registered pilot;
  अपने food-safety lead के साथ rule packs को राष्ट्रीय कानून के अनुसार अनुकूलित करें; अपना स्वयं का registry
  node चलाएँ।

**पहली सफलता।** एक दिन के लिए तीन CSV templates भरें,
`cookwala humanitarian --summary your-folder` चलाएं, और हर नंबर के नीचे एक विधि के साथ `ImpactSummary` पढ़ें।

**प्रवाह।** Offer → claim → temperature check के साथ handover → distribution → impact summary → प्रकाशित परिणाम, वे जो कुछ भी दिखाएं।

**यह उनके काम को कैसे आगे बढ़ाता है।** साइटों में तुलनीय संख्याएँ; फंडर्स के लिए साक्ष्य;
समस्या के बाद नहीं, बल्कि समस्या से पहले सुरक्षा निष्कर्ष; एक प्रारूप जिसे डोनर्स के सिस्टम पढ़ सकते हैं (HXL,
GS1, DHIS2 mappings)।

**यह समाज को कैसे आगे बढ़ाता है।** अधिक भोजन लोगों तक सुरक्षित रूप से पहुँच रहा है, उनकी गरिमा को अक्षुण्ण रखते हुए:
कोई नाम नहीं, कोई चेहरा नहीं, कोई प्रोफाइलिंग नहीं।

## 6. स्वास्थ्य: आहार विशेषज्ञ, खाद्य-सुरक्षा अधिकारी, सार्वजनिक-स्वास्थ्य एजेंसियां, देखभाल गृह

**संदेश।** सार्वजनिक मार्गदर्शन से प्राप्त, मेनू और हैंडओवर पर लागू, मशीन-जांचने योग्य पैक के रूप में पोषण और खाद्य-सुरक्षा नियम, जिसमें आपकी समीक्षा को पेशे और परिणाम द्वारा रिकॉर्ड किया जाता है। कुछ भी चिकित्सा सलाह नहीं है; पैक जो कहते हैं उसके अलावा कुछ भी दावा नहीं किया गया है।

**विकल्प।** टेम्पलेट के साथ एक pack की समीक्षा करें (दो घंटे) · national rules के अनुसार एक pack को अनुकूलित करें ·
जिन लोगों की आप सेवा करते हैं उनके लिए care rules प्रस्तावित करें · later, कार्यक्रमों से aggregate outcomes पढ़ें।

**पहली सफलता।** `profiles/humanitarian/care-vulnerable-groups.rulepack.json` और
समीक्षा टेम्पलेट खोलें; तीन नियमों को approved, changed या rejected के रूप में चिह्नित करें; समीक्षा को फाइल करें।

**प्रवाह।** Draft pack → review → status reviewed → programs adopt → findings in every
distribution → outcomes published with methods.

**यह उनके काम को कैसे आगे बढ़ाता है।** आपका मार्गदर्शन हर उस रसोई में चलता है जो इसे अपनाती है,
रोबोट रसोई सहित, जिसमें आपका पेशा रिकॉर्ड पर होता है; एक प्रकाशित करने योग्य समीक्षा; एक
निष्कर्षों का dataset (aggregate, कोई व्यक्तिगत डेटा नहीं) अनुसंधान के लिए।

**यह समाज को कैसे आगे बढ़ाता है।** बड़े पैमाने पर परोसे जाने वाले भोजन में कम सोडियम, चीनी और संतृप्त वसा; सुरक्षित hot-holding और कूलिंग; मशीन में बच्चों और बुजुर्गों की देखभाल को शामिल किया गया है।

## 7. शिक्षा: स्कूल शिक्षक, शिक्षक, प्रोफेसर, शोधकर्ता, छात्र

**Message.** खाना पकाना दुनिया में सबसे परिचित प्रक्रिया है, और Cookwala इसे एक शिक्षण वस्तु में बदल देता है: तापमान, इकाइयाँ, निष्पक्ष साझाकरण, सुरक्षा, नियम मानने वाली मशीनें। शोधकर्ताओं के लिए यह एक बेंचमार्क, एक डेटासेट प्रारूप और खुले-प्रश्नों की एक सूची है।

**विकल्प।**
- *शिक्षक:* लेसन किट (`docs/education/LESSON-KIT.md`): "what is a simmer" से लेकर "what should a machine never do" तक पाँच पाठ।
- *प्रोफेसर और छात्र:* शोध विषयों की सूची, सिम्युलेटर, परीक्षण स्थितियों के रूप में conformance vectors, LeRobot export, थीसिस-आकार की ओपन प्रॉब्लम्स।
- *शोधकर्ता:* सहमति प्राप्त executions के डेटासेट प्रकाशित करें; सिम्युलेटर के assumptions की आलोचना करें; vectors प्रस्तावित करें।

**पहली सफलता।** शिक्षक: कक्षा में ब्राउज़र dry run चलाएं और पूछें कि डिवाइस ने refusal before heat क्यों किया। छात्र: सिटी सिम्युलेटर में एक assumption बदलें और परिणाम समझाएं।

**प्रवाह।** Lesson → project → dataset → paper → RFC.

**यह उनके काम को कैसे आगे बढ़ाता है।** मुफ्त, खुला, उद्धृत करने योग्य सामग्री; एक बेंचमार्क जिसका कोई मालिक नहीं है;
RFCs के माध्यम से मानक पर सह-लेखकत्व।

**यह समाज को कैसे आगे बढ़ाता है।** एक पीढ़ी जो जानती है कि एक सुरक्षित रसोई क्या है और एक safety sheet पढ़ सकती है।

## 8. सरकार: सरकारें, मंत्रालय, शहर के अधिकारी, नियामक, राजनेता और विधायक, शासी और मानक निकाय

**संदेश।** घरेलू और व्यावसायिक कुकिंग मशीनें उन नियमों के तहत आ रही हैं जो उपकरणों और सॉफ़्टवेयर के लिए अलग-अलग लिखे गए हैं। Cookwala नियामकों को कुछ ठोस प्रदान करता है: डिवाइस पर लागू सुरक्षा सीमाएं, refusal before heat, हस्ताक्षरित रिकॉर्ड, गुमनाम घटना रिपोर्टिंग, और एक conformance suite जिसे कोई भी चला सकता है। खाद्य-दान सुरक्षा के लिए यह बिना किसी व्यक्तिगत डेटा के एक डेटा मानक प्रदान करता है। यह royalty-free है और तटस्थ शासन की ओर बढ़ रहा है।

**विकल्प।** नीति संक्षिप्त विवरण (`docs/policy/BRIEF.md`) पढ़ें · खाद्य-दान डेटा और कुकिंग-मशीन सुरक्षा के लिए मॉडल भाषा का उपयोग करें · अपने मानकों निकाय से Core 0.2 की समीक्षा करने के लिए कहें · एक राष्ट्रीय registry नोड चलाएं · अपने स्कूल-भोजन कार्यक्रम के साथ एक पायलट को वित्तपोषित करें।

**पहली सफलता।** दो-पृष्ठ का संक्षिप्त विवरण पढ़ें और रिपॉजिटरी में तीन चीजें जांचें:
safety limits pack, conformance runner, humanitarian data-protection rules।

**प्रवाह।** संक्षिप्त → एक राष्ट्रीय मानक निकाय द्वारा समीक्षा → मार्गदर्शन में संदर्भ → पायलट →
certification योजना।

**यह उनके काम को कैसे आगे बढ़ाता है।** एक तैयार, समीक्षा योग्य तकनीकी आधार; पायलटों से साक्ष्य; एक तटस्थ मानक के माध्यम से उद्योग तक एक चैनल; उन मानवीय डेटा मानकों के साथ इंटरऑपरेबिलिटी जिनका आप पहले से ही उपयोग करते हैं।

**यह समाज को कैसे आगे बढ़ाता है।** घरों में सुरक्षित मशीनें; खाद्य बचाव जो उन लोगों की रक्षा करता है जिनकी यह सेवा करता है; शहरों में कम अपशिष्ट।

## 9. पूंजी: निवेशक, उद्यमी, परोपकारी, विकास बैंक

**Message.** खाना बनाना बुनियादी ढांचा (infrastructure) बनने वाला है। मानक मुफ्त है; इसके आसपास की सेवाएँ एक व्यवसाय हैं: certification, hub सॉफ्टवेयर, सहमति प्राप्त डेटासेट, registry संचालन, पायलट। मानवीय परत एक सार्वजनिक वस्तु है जिसे विकास निधि प्रदाता पूर्व-पंजीकृत मूल्यांकन के साथ समर्थन दे सकते हैं। इस साइट पर कहीं भी कोई वित्तीय वादे नहीं किए गए हैं।

**विकल्प।** अवसर, बिजनेस मॉडल, रोडमैप, जोखिम और गवर्नेंस पढ़ें
(`/investors`) · एक पायलट या समीक्षा को फंड करें · उस कंपनी का समर्थन करें जो मुफ्त मानक के साथ सेवाएं बेचती है next · एक फंडर ऑब्जर्वर के रूप में गवर्नेंस में शामिल हों।

**पहली सफलता।** whitepaper के problem, architecture और risks अनुभागों और action plan के concern register को पढ़ें; प्रत्येक open risk सूचीबद्ध है।

**प्रवाह।** साक्ष्य (pilots, conformance, adopters) → action plan में gates → gates से जुड़ा funding → मानक के लिए neutral foundation, सेवाओं के लिए एक कंपनी।

**यह उनके काम को कैसे आगे बढ़ाता है।** ईमानदार नंबरों के साथ एक श्रेणी-परिभाषित मानक में शुरुआती स्थिति; सार्वजनिक भलाई से अलग एक निवेश योग्य सेवा कंपनी।

**यह समाज को कैसे आगे बढ़ाता है।** पूंजी उस पर जाती है जो measured है, न कि उस पर जिसका दावा किया गया है।

## 10. विचार: दार्शनिक, नीतिशास्त्री, इतिहासकार और भविष्यवादी

**Message.** जब एक मशीन दादी माँ की रेसिपी पकाती है, तो उस ज्ञान का स्वामी कौन है? स्वचालित देखभाल में गरिमा का क्या अर्थ है? एक household का रोबोट क्या जान सकता है, और इसके अलावा और कौन इसे जान सकता है? Cookwala ने कोड में इन सवालों के बारे में चुनाव किए हैं; निबंध (`docs/essays/`) बताते हैं कि वे क्या थे और असहमति को आमंत्रित करते हैं।

**विकल्प।** निबंध पढ़ें · प्रतिक्रिया लिखें · एक rule propose करें (एक RFC एक schema के साथ एक दार्शनिक तर्क है) · household context profile की ethics review में बैठें।

**पहली सफलता।** household data और facet registry के travel rules पर निबंध पढ़ें;
एक ऐसा facet खोजें जिसका default आप बदलना चाहेंगे, और बताएं क्यों।

**प्रवाह।** Essay → public comment → RFC → changed default.

**यह उनके काम को कैसे आगे बढ़ाता है।** एक लाइव केस जहाँ नैतिक स्थितियाँ running rules बन जाती हैं,
तर्क के सार्वजनिक रिकॉर्ड के साथ।

**यह समाज को कैसे आगे बढ़ाता है।** मशीनों के लाखों घरों में पहुँचने से पहले, अंतरंग डेटा और सांस्कृतिक विरासत के बारे में निर्णय खुले तौर पर लिए जाते हैं।

## 11. हर कोई: वे लोग जो भोजन, अपशिष्ट, नौकरियों, जलवायु और भविष्य की परवाह करते हैं

**Message.** Cookwala एक रेसिपी लिखने का एक तरीका है ताकि कोई भी, या कुछ भी, इसे सुरक्षित रूप से पका सके, और उस भोजन के लिए एक तरीका है जिसे फेंक दिया जाता, ताकि वह किसी ऐसे व्यक्ति तक पहुँच सके जिसे इसकी आवश्यकता है। यह मुफ्त है, यह किसी कंपनी का नहीं है, और यह बताता है कि यह क्या नहीं जानता है।

**विकल्प।** dry run आज़माएँ · एक simulator चलाएँ · रेसिपी पढ़ें · एक ऐसी रेसिपी लिखें जिसे आप पसंद करते हैं · roadmap का पालन करें · किसी food bank या स्कूल को इसके बारे में बताएं।

**पहली सफलता।** `dry run` में डिवाइस बदलें और देखें कि एक स्टेप को `refusal before heat` किया जाता है; पढ़ें कि क्यों।

**प्रवाह।** जिज्ञासा → एक रेसिपी → एक रसोई के साथ एक बातचीत जो इसका उपयोग कर सकती है।

**यह उनके जीवन को कैसे आगे बढ़ाता है।** घर में सुरक्षित मशीनें, उनकी अपनी रेसिपी सुरक्षित, बिना पैसे दिए मदद करने का एक तरीका।

**यह समाज को कैसे आगे बढ़ाता है।** कम बर्बादी, सुरक्षित भोजन, ऐसी मशीनें जो उन लोगों की सेवा करती हैं जो अपने लिए खाना नहीं बना सकते, और मानव समय की वापसी।

## 12. नौकरियां और गरिमा, स्पष्ट रूप से कहा गया
