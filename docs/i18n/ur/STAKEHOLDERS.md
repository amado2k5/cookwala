ہر قطار کے پیچھے تین مقاصد: بھوک ختم کرنے میں مدد کرنا، لوگوں کو صحت مند بنانا، لوگوں کے لیے روبوٹس کو کام پر لگانا۔

## 1. Builders: ڈویلپرز، روبوٹ اور اپلائنس بنانے والے، ایمبیڈڈ انجینئرز، AI-agent بنانے والے، اسمارٹ ہوم اور پلیٹ فارم ڈویلپرز، اوپن سورس کنٹریبیوٹرز

**پیغام۔** روبوٹس اور آلات حرکت کرنا سیکھ رہے ہیں۔ کسی نے بھی، ایسی شکل میں جو مشین چیک کر سکے، یہ نہیں لکھا کہ "simmer" کا کیا مطلب ہے، کب چکن محفوظ ہے، یا کب کسی قدم کو refusal before heat کرنا چاہیے۔ Cookwala وہی تہہ ہے: ایسی ترکیبیں جن کا مشین منصوبہ بندی کر سکتا ہے، وہ اختتامی شرائط جنہیں وہ measure کر سکتا ہے، اور وہ حفاظتی حدود جنہیں وہ خود پر نافذ کرتا ہے۔ یہ کھلا، رائلٹی فری، ماڈل کے لحاظ سے غیر جانبدار اور ڈیوائس کے لحاظ سے غیر جانبدار ہے، اور یہ ایک conformance سوٹ کے ساتھ آتا ہے جسے آپ آج ہی چلا سکتے ہیں۔

**آپشنز۔**
- *Light:* براؤزر کا dry run چلائیں؛ Core 0.2 پڑھیں (ایک شام)۔
- *Medium:* `pip install -e sdk/python` کریں، مثال کے طور پر دی گئی ریسیپیز کے خلاف اپنے ڈیوائس کی صلاحیتوں کا dry-run کریں، conformance vectors چلائیں، ریفرنس hub شروع کریں۔
- *Deep:* کسی ڈیوائس یا hub پر Core API نافذ کریں، conformance رپورٹ شائع کریں، ڈیوائس کو directory میں شامل کریں، RFC تجویز کریں، ROS 2 bridge node لکھیں، agent-safety benchmark میں attack cases شامل کریں۔

**پہلی کامیابی (15 منٹ کے اندر)۔**
```bash
git clone https://github.com/amado2k5/cookwala && cd cookwala && pip install -e sdk/python
cookwala dryrun examples/koshari.cookwala.json --device examples/capabilities/robot-arm.json
# refused: cw.op.boil, missing_capability (and later: no oil thermometer, no deep frying)
cookwala dryrun examples/koshari.cookwala.json --device examples/capabilities/robot-arm.json --human-present
cookwala conformance --report report.json          # 106 vectors; a signed-ready report
```

**Flow.** Dry run → reference hub کے خلاف Core API کو نافذ کریں → conformance پاس کریں →
رپورٹ شائع کریں → ڈیوائس کو فہرست میں شامل کریں → باہمی رضامندی سے حاصل شدہ execution logs، LeRobot datasets اور
OpenTelemetry traces بن جاتے ہیں۔

**یہ ان کے کام کو کیسے آگے بڑھاتا ہے۔** کھانا پکانے کے لیے ایک مشترکہ ٹاسک تعریف اور کامیابی کا ٹیسٹ، ایک عوامی بینچ مارک کے ساتھ جس کے خلاف پیمائش کی جا سکے؛ ہر قسم کے پکوانوں میں تراکیب بغیر انہیں لکھے؛ ایک حفاظتی کہانی جسے ریگولیٹرز پڑھ سکیں؛ conformance رپورٹس بطور سیلز دستاویز؛ ایک ایسے معیار میں پہل کرنے والے کا مقام جس کا نظم و نسق اس کے نافذ کرنے والے کریں گے۔

**یہ معاشرے کو کیسے آگے بڑھاتا ہے۔** کچن کی آگ اور خوراک سے ہونے والی بیماریوں میں کمی، ایسی مشینوں کے ذریعے جو اندازہ لگانے کے بجائے refusal before heat کرتی ہیں؛ ایسی مشینیں جو چند کے بجائے دنیا کے پکوانوں کو وراثت میں حاصل کرتی ہیں۔

## 2. کمپنیاں: اسٹارٹ اپس، انٹرپرائزز، فوڈ کمپنیاں، گروسرز اور ڈیلیوری، ریسٹورنٹس اور فوڈ سروس، انشورنس کمپنیاں، سرٹیفائرز، سیلز اور پارٹنرشپ ٹیمیں

**پیغام۔** ہر کمپنی جو خوراک سے وابستہ ہے، اگلے چند سالوں میں کوکنگ مشینوں اور AI ایجنٹس سے واسطہ رکھے گی۔ Cookwala آپ کو ان سب کے لیے ایک انٹرفیس فراہم کرتا ہے، جو واحد ہے جس میں ڈیوائس پر حفاظتی حدود نافذ ہیں اور ایسے ریکارڈز ہیں جن کا آپ آڈٹ کر سکتے ہیں۔ گروسرز اور ڈیلیوری کے لیے: ڈیلیوری ونڈوز اور الرجن کی ضروریات وصول کریں، کسی خاندان کا شیڈول کبھی نہیں۔ انشورنس فراہم کرنے والوں اور سرٹیفائرز کے لیے: ایک conformance رپورٹ فارمیٹ اور ایک انسیڈنٹ-رپورٹ فیڈ جو خاص طور پر آپ کے لیے ڈیزائن کی گئی ہے۔

**آپشنز۔**
- *Light:* Investors اور partners پیج اور trust پیجز پڑھیں؛ اپنے پروڈکٹس کو ingredient classes اور operations کے ساتھ میپ کریں۔
- *Medium:* ایک offer feed (market profile, experimental) یا کسی مقامی پروگرام (Humanitarian Profile) کو surplus offer شائع کریں؛ اس agent پر agent-safety benchmark چلائیں جسے آپ deploy کرنے کا منصوبہ رکھتے ہیں۔
- *Deep:* کسی پروڈکٹ میں Core API نافذ کریں؛ conformance verification کو سپانسر کریں؛ جب steering committee تشکیل ہو جائے تو اس میں شامل ہوں؛ certification path اپنائیں۔

**پہلی کامیابی۔** ایک پروڈکٹ لائن کو GTINs اور الرجن کریڈنشلز کے ساتھ مارکیٹ `Offer` میں تبدیل کریں، اسے ویلیڈیٹ کریں، اور دیکھیں کہ یہ کن مثال کے طور پر ریسیپیز کی فراہمی کر سکتا ہے۔

**Flow.** فیڈ پیش کریں → households سے derived constraints → اپنے خود کے checkout کے ذریعے آرڈرز → fulfilment events → execution reports سے reputation (رضامندی کے ساتھ)۔

**یہ ان کے کام کو کیسے آگے بڑھاتا ہے۔** درجن بھر وینڈر انٹیگریشنز کے بجائے ایک نیوٹرل لیئر تک رسائی؛ ڈیمانڈ سگنلز (later، مقابلے کے قانون کے جائزے کے بعد) جو فضول خرچی کو کم کرتے ہیں؛ certification جس کی قیمت انشورنس کمپنیاں لگا سکیں؛ حفاظت کا ایک عوامی ریکارڈ۔

**یہ معاشرے کو کیسے آگے بڑھاتا ہے۔** اسٹور اور پلیٹ کے درمیان کم خوراک ضائع ہوتی ہے؛ surplus کے گلنے سے پہلے کچن تک پہنچنا؛ گھروں میں ایسی مشینیں جنہیں غیر محفوظ کاموں کے لیے راضی نہیں کیا جا سکتا۔

## 3. فراہم کنندگان: grocers، فارمز اور کوآپریٹوز، ڈیلیوری، انرجی، AI اور ماڈل وینڈرز، ریسیپی پبلشرز

**پیغام۔** فراہم کنندگان Cookwala میں ساتھیوں کے طور پر شامل ہوتے ہیں، کرایہ داروں کے طور پر نہیں۔ ایک دکاندار یا ڈیلیوری سروس کو ایک constraint ملتا ہے، کبھی کسی household کے facts نہیں ملتے۔ ایک AI vendor کو ایک benchmark ملتا ہے جو دکھاتا ہے کہ اس کا model کچن میں محفوظ ہے اور آج استعمال کرنے کے لیے ایک MCP server ملتا ہے۔ ایک recipe publisher ہر recipe پر اپنا نام رکھتا ہے اور ایک static folder سے دستخط شدہ catalog شائع کر سکتا ہے۔

**Options.** ایک کیٹلاگ (recipes) شائع کریں · ایک offer feed شائع کریں · agent-safety benchmark چلائیں · ایک registry node چلائیں · SMS کے ذریعے surplus پیش کریں۔

**پہلی کامیابی۔** Recipe publisher: `cookwala init my-dish`, edit, `cookwala validate`,
`cookwala hash`; آپ کا catalog ایک folder ہے جس میں `/.well-known/cookwala.json` ہے۔ AI vendor:
MCP server شامل کریں اور دس agent-safety cases چلائیں۔

**Flow.** Catalog یا feed → آپ کے ثابت شدہ namespace کے تحت registry entry → اگر کچھ غلط ہو جائے تو recall feed → نتائج سے reputation۔

**یہ ان کے کام کو کیسے آگے بڑھاتا ہے۔** ایک ہی فارمیٹ کے ذریعے ہر ڈیوائس اور ایجنٹ تک پہنچیں؛
دستخط کے ذریعے کریڈٹ اور ثبوت؛ ایک سیفٹی بینچ مارک جو ایمانداری سے پاس ہونے پر مارکیٹنگ اثاثہ بن جاتا ہے۔

**یہ معاشرے کو کیسے آگے بڑھاتا ہے۔** تراکیب منسوب رہتی ہیں؛ وہ ایجنٹس جو لوگوں کے لیے کام کرتے ہیں انہیں قابلِ اعتماد بنانے سے پہلے measured کیا جاتا ہے۔

## 4. خوراک: کسان، باورچی اور شیف، گھریلو باورچی، ترکیب بنانے والے، کوکنگ اسکولز

**پیغام۔** Cookwala کے لیے لکھی گئی ایک ترکیب آپ کا نام اور آپ کا پکوان ہر اس ڈیوائس پر زندہ رکھتی ہے جو اسے پکاتی ہے، ان مراحل کے ساتھ جنہیں مشین کو کبھی بھی نہیں چھوڑنا چاہیے، جو لکھے ہوئے ہیں۔ ضرورت سے زیادہ پیداوار والا ایک فارم اسے SMS کے ذریعے فہرست میں شامل کر سکتا ہے اور اسی دن کچن تک پہنچا سکتا ہے۔ ایک ککنگ اسکول کھانے کی حفاظت اس فارمیٹ کے ساتھ سکھا سکتا ہے جو خود کو چیک کرتا ہے۔

**آپشنز۔**
- *کسان:* `FARM 120KG TOMATO A BB0411` کو کسی پروگرام کے گیٹ وے (جہاں موجود ہو) پر بھیجیں؛
  later، سپلائی اور ڈیمانڈ کے سگنلز پڑھیں۔
- *کک اور شیف:* اپنی یادداشت میں موجود کسی ایک ترکیب کو Cookwala ترکیب میں تبدیل کریں؛ اپنی زبان میں مرحلہ وار جملوں کا جائزہ لیں؛ later، کریڈٹ کے ساتھ رضامندی شدہ سیشنز ریکارڈ کریں۔
- *اسکول:* نو مثال کے طور پر دی گئی ترکیبوں کو تدریسی کیسز کے طور پر استعمال کریں؛ اپنی ترکیبیں شامل کریں۔

**پہلی کامیابی۔** Cooks: `cookwala init`, ہر heat step کے لیے ایک end condition کے ساتھ ایک recipe لکھیں، اس کی validation کریں۔ Farmers: ایک ایسے program کو ایک SMS offer بھیجیں جو profile کو چلاتا ہے (ابھی تک کوئی نہیں چل رہا؛ parser اور vectors موجود ہیں)۔

**Flow.** ترکیب → validation → catalog → آلات پر dry run → execution logs دکھاتے ہیں کہ یہ حقیقی مشینوں پر کیسا کارکردگی دکھاتا ہے → شواہد کے ساتھ نظرثانی۔

**یہ ان کے کام کو کیسے آگے بڑھاتا ہے۔** ایسی منسوبیت جو سفر کرے؛ ایک ایسی ترکیب جسے دوسرے ممالک میں مشینوں کے ذریعے پکایا جا سکے؛ کسانوں کے لیے، فالتو مقدار کو ضائع کرنے کے بجائے کھانوں میں تبدیل کرنے کا ایک طریقہ۔

**یہ معاشرے کو کیسے آگے بڑھاتا ہے۔** پکوان کا ورثہ ویڈیو کے بجائے عملی علم کے طور پر محفوظ کیا جاتا ہے؛
کھیت کے دہانے پر ہونے والا ضیاع کم ہوتا ہے۔

## 5. انسانی ہمدردی: NGOs، food banks، کمیونٹی کچن، اسکول کے کھانے کے پروگرام، ریلیف ایجنسیاں، عطیہ دہندگان

**پیغام۔** Humanitarian Profile فونز اور اسپریڈ شیٹس کے ذریعے surplus food کو پلیٹوں تک پہنچاتا ہے، cold-chain چیکس کا ریکارڈ رکھتا ہے، کھانوں کی گنتی کرتا ہے، اور **کوئی ذاتی ڈیٹا** نہیں رکھتا۔ یہ روبوٹس، ایپس یا انٹرنیٹ کے بغیر کام کرتا ہے۔ یہ آپ کو ایسے نمبر فراہم کرتا ہے جن کا آپ دفاع کر سکتے ہیں: بچائے گئے کلوگرام، پیش کیے گئے کھانے، nutrition pass rate، فی کھانا لاگت، کلیم کرنے کا وقت، حفاظتی واقعات، ہر ایک اپنے طریقہ کار کے ساتھ۔

**آپشنز۔**
- *Light:* پروفائل اور پائلٹ پروٹوکول پڑھیں؛ SMS walkthrough آزمائیں۔
- *Medium:* ایک سائٹ پر چار ہفتوں کے لیے CSV templates چلائیں (level H0) اور ایک
  impact summary کا حساب لگائیں۔
- *Deep:* ایک baseline اور ایک آزاد ایویلیوایٹر کے ساتھ 12 ہفتوں کا pre-registered pilot؛
  اپنے food-safety lead کے ساتھ rule packs کو قومی قانون کے مطابق ڈھالیں؛ اپنا خود کا registry
  node چلائیں۔

**پہلی کامیابی۔** ایک دن کے لیے تینوں CSV templates پُر کریں،
`cookwala humanitarian --summary your-folder` چلائیں، اور ہر نمبر کے نیچے ایک طریقہ کار کے ساتھ `ImpactSummary` پڑھیں۔

**Flow.** پیشکش → دعویٰ → درجہ حرارت کی جانچ کے ساتھ حوالگی → تقسیم → اثر کا خلاصہ → شائع شدہ نتائج، وہ جو بھی دکھائیں۔

**یہ ان کے کام کو کیسے آگے بڑھاتا ہے۔** سائٹس کے درمیان قابل موازنہ اعداد و شمار؛ فنڈز دینے والوں کے لیے شواہد؛
مسئلے کے بعد نہیں، بلکہ مسئلے سے پہلے حفاظتی نتائج؛ ایک فارمیٹ جسے عطیہ دہندگان کے سسٹم پڑھ سکتے ہیں (HXL,
GS1, DHIS2 mappings)۔

**یہ معاشرے کو کیسے آگے بڑھاتا ہے۔** زیادہ خوراک لوگوں تک بحفاظت پہنچنا، ان کی عزتِ نفس برقرار رکھتے ہوئے:
کوئی نام نہیں، کوئی چہرہ نہیں، کوئی پروفائلنگ نہیں۔

## 6. صحت: ماہرینِ غذا، فوڈ سیفٹی افسران، عوامی صحت کی ایجنسیاں، دیکھ بھال کے مراکز

**پیغام۔** غذائیت اور خوراک کی حفاظت کے اصول مشین کے ذریعے چیک کیے جانے والے packs کے طور پر، جو عوامی رہنمائی سے اخذ کیے گئے ہیں، مینو اور ہینڈ اوورز پر لاگو ہوتے ہیں، جن کا آپ کا جائزہ پیشے اور نتیجے کے ذریعے ریکارڈ کیا جاتا ہے۔ کچھ بھی طبی مشورہ نہیں ہے؛ کچھ بھی اس سے زیادہ دعویٰ نہیں کیا گیا جو packs کہتے ہیں۔

**Options.** ٹیمپلیٹ کے ساتھ ایک pack کا جائزہ لیں (دو گھنٹے) · ایک pack کو قومی قواعد کے مطابق ڈھالیں ·
جن لوگوں کی آپ خدمت کرتے ہیں ان کے لیے دیکھ بھال کے قواعد تجویز کریں · later، پروگراموں سے مجموعی نتائج پڑھیں۔

**پہلی کامیابی۔** `profiles/humanitarian/care-vulnerable-groups.rulepack.json` اور
ریویو ٹیمپلیٹ کھولیں؛ تین رولز کو approved، changed یا rejected کے طور پر نشان زد کریں؛ ریویو فائل کریں۔

**Flow.** ڈرافٹ پیک $\rightarrow$ جائزہ $\rightarrow$ status reviewed $\rightarrow$ پروگرامز اپنائیں $\rightarrow$ ہر تقسیم میں نتائج $\rightarrow$ طریقوں کے ساتھ نتائج شائع کیے گئے۔

**یہ ان کے کام کو کیسے آگے بڑھاتا ہے۔** آپ کی رہنمائی ہر اس کچن میں چلتی ہے جو اسے اپناتا ہے، بشمول روبوٹ کچنز، جس میں آپ کا پیشہ ریکارڈ پر ہوتا ہے؛ ایک قابلِ اشاعت ریویو؛ تحقیق کے لیے نتائج کا ایک ڈیٹاسٹ (مجموعی، کوئی ذاتی ڈیٹا نہیں)۔

**یہ معاشرے کو کیسے آگے بڑھاتا ہے۔** بڑے پیمانے پر فراہم کیے جانے والے کھانوں میں کم سوڈیم، چینی اور سیچوریٹڈ فیٹ؛ محفوظ ہاٹ-ہولڈنگ اور کولنگ؛ مشین میں بچوں اور بوڑھے لوگوں کی دیکھ بھال شامل ہے۔

## 7. تعلیم: اسکول کے اساتذہ، معلمین، پروفیسرز، محققین، طلباء

**پیغام۔** کھانا پکانا دنیا کا سب سے مانوس عمل ہے، اور Cookwala اسے ایک تدریسی چیز میں بدل دیتا ہے: درجہ حرارت، یونٹس، منصفانہ تقسیم، حفاظت، وہ مشینیں جو اصولوں پر عمل کرتی ہیں۔ محققین کے لیے یہ ایک بینچ مارک، ایک ڈیٹا سیٹ فارمیٹ اور کھلے مسائل کی فہرست ہے۔

**آپشنز۔**
- *اساتذہ:* سبق کٹ (`docs/education/LESSON-KIT.md`): پانچ اسباق "what is a
  simmer" سے لے کر "what should a machine never do" تک۔
- *پروفیسرز اور طلباء:* تحقیقی موضوعات کی فہرست، سیمولیٹرز، ٹیسٹ کنڈیشنز کے طور پر conformance
  ویکٹرز، LeRobot ایکسپورٹ، تھیسس کے حجم کے اوپن مسائل۔
- *محققین:* رضامندی کے ساتھ کیے گئے executions کے ڈیٹا سیٹس شائع کریں؛ سیمولیٹرز کے
  assumptions پر تنقید کریں؛ ویکٹرز تجویز کریں۔

**پہلی کامیابی۔** اساتذہ: کلاس میں browser dry run چلائیں اور پوچھیں کہ ڈیوائس نے کیوں انکار کیا۔ طلباء: سٹی سیمولیٹر میں ایک assumption تبدیل کریں اور نتیجے کی وضاحت کریں۔

**Flow.** سبق → پروجیکٹ → ڈیٹا سیٹ → مقالہ → RFC.

**یہ ان کے کام کو کیسے آگے بڑھاتا ہے۔** مفت، کھلا، اور حوالہ دینے کے قابل مواد؛ ایک بینچ مارک جس کا کوئی مالک نہیں؛
RFCs کے ذریعے معیار پر સહ-مصنف (co-authorship)۔

**یہ معاشرے کو کیسے آگے بڑھاتا ہے۔** ایک نسل جو جانتی ہے کہ محفوظ کچن کیا ہوتا ہے اور ایک safety sheet پڑھ سکتی ہے۔

## 8. حکومت: حکومتیں، وزارتیں، شہر کے حکام، ریگولیٹرز، سیاست دان اور قانون ساز، حکمران اور معیاری ادارے

**پیغام۔** گھریلو اور تجارتی کوکنگ مشینیں ان ضوابط کے تحت آ رہی ہیں جو آلات اور سافٹ ویئر کے لیے علیحدہ لکھے گئے ہیں۔ Cookwala ریگولیٹرز کو کچھ ٹھوس فراہم کرتا ہے جس کی طرف اشارہ کیا جا سکے: ڈیوائس پر نافذ کردہ حفاظتی حدود، refusal before heat، دستخط شدہ ریکارڈز، گمنام واقعہ رپورٹنگ، اور ایک conformance suite جسے کوئی بھی چلا سکتا ہے۔ فوڈ ڈونیشن کی حفاظت کے لیے یہ بغیر کسی ذاتی ڈیٹا کے ایک ڈیٹا اسٹینڈرڈ فراہم کرتا ہے۔ یہ رائلٹی فری ہے اور غیر جانبدارانہ گورننس کی طرف بڑھ رہا ہے۔

**آپشنز۔** پالیسی بریف (`docs/policy/BRIEF.md`) پڑھیں · فوڈ-ڈونیشن ڈیٹا اور کوکنگ-مشین سیفٹی کے لیے ماڈل زبان استعمال کریں · اپنے اسٹینڈرڈز باڈی سے Core 0.2 کا جائزہ لینے کا کہیں · ایک نیشنل رجسٹری نوڈ چلائیں · اپنے اسکول-میل پروگرام کے ساتھ ایک پائلٹ کو فنڈ کریں۔

**پہلی کامیابی۔** دو صفحات کا خلاصہ پڑھیں اور ریپوزٹری میں تین چیزیں چیک کریں:
safety limits pack، conformance runner، humanitarian data-protection rules۔

**Flow.** مختصر → قومی معیارات کے ادارے کے ذریعے جائزہ → رہنمائی میں حوالہ → پائلٹ →
certification سکیم۔

**یہ ان کے کام کو کیسے آگے بڑھاتا ہے۔** ایک تیار شدہ، قابلِ جائزہ تکنیکی بنیاد؛ پائلٹس سے شواہد؛ ایک غیر جانبدارانہ معیار کے ذریعے صنعت تک ایک چینل؛ ان انسانی ہمدردی کے ڈیٹا معیارات کے ساتھ باہمی عمل پذیری جو آپ پہلے سے استعمال کرتے ہیں۔

**یہ معاشرے کو کیسے آگے بڑھاتا ہے۔** گھروں میں محفوظ مشینیں؛ خوراک کی بچاؤ (food rescue) جو ان لوگوں کی حفاظت کرتی ہے جن کی وہ خدمت کرتی ہے؛ شہروں میں کم فضلے۔

## 9. سرمایہ: سرمایہ کار، کاروباری افراد، فلاحی ادارے، ترقیاتی بینک

**پیغام۔** کھانا پکانا اب انفراسٹرکچر بننے والا ہے۔ معیار مفت ہے؛ اس کے گرد موجود خدمات ایک کاروبار ہیں: certification، hub سافٹ ویئر، رضامندی سے حاصل کردہ datasets، registry آپریشنز، پائلٹس۔ انسانی ہمدردی کا درجہ ایک عوامی بھلائی ہے جسے ترقیاتی فنڈز فراہم کرنے والے پہلے سے رجسٹرڈ تشخیص کے ساتھ سپورٹ کر سکتے ہیں۔ اس سائٹ پر کہیں بھی کوئی مالی وعدہ نہیں کیا گیا ہے۔

**آپشنز۔** موقع، بزنس ماڈل، روڈ میپ، خطرات اور گورننس پڑھیں
(`/investors`) · ایک پائلٹ یا ریویو کے لیے فنڈ فراہم کریں · ایسی کمپنی کی حمایت کریں جو مفت اسٹینڈرڈ کے ساتھ سروسز فروخت کرتی ہے `next` · فنڈر آبزروور کے طور پر گورننس میں شامل ہوں۔

**پہلی کامیابی۔** وائٹ پیپر کے problem، architecture اور risks کے سیکشنز اور action plan کے concern register کو پڑھیں؛ ہر کھلا ہوا risk فہرست میں شامل ہے۔

**Flow.** شواہد (pilots, conformance, adopters) → ایکشن پلان میں گیٹس → گیٹس سے منسلک فنڈنگ → معیار کے لیے غیر جانبدار بنیاد، خدمات کے لیے ایک کمپنی۔

**یہ ان کے کام کو کیسے آگے بڑھاتا ہے۔** ایماندارانہ اعداد و شمار کے ساتھ ایک کیٹیگری-ڈیفائننگ اسٹینڈرڈ میں ابتدائی پوزیشن؛ ایک قابلِ سرمایہ کاری سروسز کمپنی جو عوامی بھلائی سے الگ ہو۔

**یہ معاشرے کو کیسے آگے بڑھاتا ہے۔** سرمایہ اس چیز پر جاتا ہے جو measured ہو، نہ کہ اس پر جس کا دعویٰ کیا گیا ہو۔

## 10. سوچ: فلسفی، اخلاقیات دان، مورخین اور مستقبل بین

**پیغام۔** جب ایک مشین دادی کی ترکیب پکاتی ہے، تو اس علم کا مالک کون ہے؟ خودکار دیکھ بھال میں وقار کا کیا مطلب ہے؟ ایک household کا روبوٹ کیا جان سکتا ہے، اور مزید کون اسے جان سکتا ہے؟ Cookwala نے کوڈ میں ان سوالات کے بارے میں انتخاب کیے ہیں؛ مضامین (`docs/essays/`) بتاتے ہیں کہ وہ کیا تھے اور اختلاف کی دعوت دیتے ہیں۔

**Options.** مضامین پڑھیں · جواب لکھیں · ایک rule تجویز کریں (ایک RFC ایک schema کے ساتھ فلسفیانہ بحث ہے) · household context profile کے ethics review میں شامل ہوں۔

**پہلی کامیابی۔** household data اور facet registry کے travel rules پر مضمون پڑھیں؛
ایک ایسا facet تلاش کریں جس کا default آپ تبدیل کرنا چاہیں گے، اور بتائیں کیوں۔

**Flow.** مضمون → عوامی تبصرہ → RFC → تبدیل شدہ ڈیفالٹ۔

**یہ ان کے کام کو کیسے آگے بڑھاتا ہے۔** ایک لائیو کیس جہاں اخلاقی پوزیشنز چلتے ہوئے rules بن جاتی ہیں،
بحث کے عوامی ریکارڈ کے ساتھ۔

**یہ معاشرے کو کیسے آگے بڑھاتا ہے۔** ذاتی ڈیٹا اور ثقافتی ورثے کے بارے میں فیصلے مشینوں کے لاکھوں گھروں میں پہنچنے سے پہلے کھلے عام کیے جاتے ہیں۔

## 11. ہر کوئی: وہ لوگ جو خوراک، فضلے، ملازمتوں، آب و ہوا اور مستقبل کی فکر کرتے ہیں

**پیغام۔** Cookwala ایک ترکیب لکھنے کا طریقہ ہے تاکہ کوئی بھی، یا کوئی بھی چیز، اسے محفوظ طریقے سے پکا سکے، اور اس خوراک کے لیے ایک طریقہ ہے جسے پھینک دیا جاتا تاکہ وہ کسی ایسے شخص تک پہنچ سکے جسے اس کی ضرورت ہو۔ یہ مفت ہے، یہ کسی کمپنی کی ملکیت نہیں ہے، اور یہ بتاتا ہے کہ یہ کیا نہیں جانتا۔

**Options.** dry run آزمائیں · simulator چلائیں · ترکیبیں پڑھیں · ایک ایسی ترکیب لکھیں جو آپ کو پسند ہو · roadmap پر عمل کریں · کسی food bank یا اسکول کو اس کے بارے میں بتائیں۔

**پہلی کامیابی۔** `dry run` میں ڈیوائس تبدیل کریں اور ایک قدم کو `refusal before heat` ہوتے ہوئے دیکھیں؛ پڑھیں کہ کیوں۔

**Flow.** تجسس → ایک ترکیب → ایک کچن کے ساتھ ایک گفتگو جو اسے استعمال کر سکتا ہے۔

**یہ ان کی زندگی کو کیسے آگے بڑھاتا ہے۔** گھر میں محفوظ مشینیں، ان کی اپنی تراکیب محفوظ، رقم دیے بغیر مدد کرنے کا ایک طریقہ۔

**یہ معاشرے کو کیسے آگے بڑھاتا ہے۔** کم فضول خرچ، محفوظ خوراک، ایسی مشینیں جو ان لوگوں کی خدمت کرتی ہیں جو اپنے لیے کھانا نہیں پکا سکتے، اور انسانی وقت کی واپسی۔

## 12. ملازمتیں اور وقار، صاف الفاظ میں

کھانا پکانے والی مشینیں کام کو تبدیل کر دیں گی۔ Cookwala کے پوزیشنز: انسان ہمیشہ کھانا پکا سکتے ہیں؛ ابتدائی استعمال ان لوگوں کے لیے ہے جو اپنے لیے کھانا نہیں پکا سکتے اور ان کمیونٹی کچن کے لیے جن میں ہاتھوں کی کمی ہے؛ ترکیب جہاں کہیں بھی پکائی جائے، اس پر باورچی کا نام رہے گا؛ لیبر کی آواز کی اسٹیئرنگ کمیٹی میں نشست ہوگی؛ نئے کردار (recipe engineers، food-robot technicians، certifiers، rule-pack reviewers) تعداد کا وعدہ کیے بغیر نامزد کیے جاتے ہیں۔
