كوكوالا لوكلاء الذكاء الاصطناعي، دون خادم تشغّله

خادم MCP لـ Claude وCodex وCopilot وCursor وWindsurf وDevin وAntigravity وأي وكيل آخر. يبحث في الوصفات ويقرؤها، ويجري تجربة جافة لوصفة على جهاز، ويفحص سجل حرارة أو تفويض وكيل أو رسالة إنقاذ غذاء، ويبحث عن الوصفات في fifi.cooking. للقراءة فقط، ولا يبدأ الطهي أبدًا.

التثبيتدليل وكلاء الذكاء الاصطناعيجرّب الاختبار في خمس دقائقجرّبه في متصفحك

التثبيت بسطر واحد

  1. Claude Code

    claude mcp add cookwala -- npx -y @cookwala/mcp

  2. Codex

    codex mcp add cookwala -- npx -y @cookwala/mcp

  3. Claude Desktop وCursor وWindsurf وAntigravity وGemini CLI وCopilot CLI: أضف هذا إلى ملف إعداد MCP في العميل.

    {
  "mcpServers": {
    "cookwala": { "command": "npx", "args": ["-y", "@cookwala/mcp"] }
  }
}

  4. VS Code (Copilot) ووكيل Copilot السحابي وDevin لكلٍّ منها ملف أو صفحة إعدادات؛ الأمر نفسه. كل العملاء مع الملف الدقيق.

يحتاج Node 20 أو أحدث. منشور على npm باسم @cookwala/mcp (الإصدار 0.2.0) ومُدرَج في سجل MCP الرسمي باسم ai.cookwala/cookwala. تجريبي: قد تتغير أسماء الأدوات.

لماذا لا شيء للاستضافة

هذا الموقع ملفات ثابتة على GitHub Pages، وهي لا تستطيع الرد على طلب MCP بعيد. لذلك لا يعيش الخادم هنا. يشغّله وكيلك على جهازك عبر stdio، ويقرأ الملفات العامة نفسها التي تفتحها في المتصفح: الفهرس والوصفات والمفردات وأجهزة الأمثلة.

كل ملف فهرس يُفحص مقابل البصمة في البيان، وتُعاد حوسبة بصمة كل وصفة قبل إرجاع أي شيء. عند عدم التطابق يُرجَع خطأ دون محتوى. بعد التشغيل الأول يعمل دون اتصال من ذاكرته المؤقتة. لا يرسل أي قياسات ولا حسابات فيه.

وهناك أيضًا نقطة اتصال مستضافة اختيارية، mcp.cookwala.ai، على Cloudflare وليست على هذا الموقع. تقدّم الأدوات نفسها للقراءة فقط، وهي موجودة ليتمكن دليل مثل mcprush.com من إدراجها وعدّ الاستدعاءات إليها. تحتاج إلى رمز، فاستخدم حزمة npm أعلاه مع وكيلك. التفاصيل.

ست عشرة أداة للقراءة فقط

كل أداة موسومة للقراءة فقط. النتائج JSON منظَّم. نص الوصفة يعود بياناتٍ لا تعليمات.

البحث والقراءة

search_recipes (بالكلمات أو المطبخ أو الطبق أو المستوى أو المجموعة أو خلوّ من مسبب حساسية)، وget_recipe (ملخص أو مكونات أو عملية أو نص أو كامل، مع التحقق من البصمة)، وlist_collections.

هل يطبخها هذا الجهاز؟

dry_run على جهاز جاهز أو على قدراتك، وlist_device_presets، وexplain_step. مقبولة أو مرفوضة مع السبب قبل أن يسخن أي شيء.

النطاقات الآمنة

check_envelope يفحص سجل حرارة مقابل نطاق العملية مع الارتفاع. وlist_operations يعرض مظروف كل عملية وسلّم حساساتها.

سلامة الوكيل

check_mandate يقول إن كان الإجراء داخل تفويض موقَّع. وverify_recipe يعيد حوسبة بصمة الوصفة. وverify_certification وcurrent_certifications يتحققان من شهادات الحلال والكوشر وغيرها بمفاتيح الجهات التي تثق بها. لا يستطيع أي منها بدء شيء أو تغييره.

إنقاذ الغذاء

parse_sms يحوّل رسالة الملف الإنساني (OFFER وFARM وCLAIM وHAND وDIST وMENU) إلى أمر منظَّم، مع الأرقام العربية.

fifi.cooking

fifi_search وfifi_source تجدان وصفات لم تدخل الفهرس بعد، بقواعد الحقوق نفسها: الخطوات حيث يجوز عرضها فقط.

وستة موارد (cookwala://recipe/<id> والمخططات وأي صفحة توثيق وأجهزة الأمثلة وقائمة العمليات وllms.txt) وثلاثة قوالب طلب. المرجع الكامل.

fifi.cooking ومعيار كوكوالا

fifi.cooking هو المكان الذي تُكتب فيه الوصفات. وكوكوالا هو الصيغة المعيارية التي تُنشر بها: وثيقة لكل وصفة، ببصمة وترخيص ونسب ورابط إلى الصفحة الأصلية. يقرأ الوكلاء هذه الصيغة عبر get_recipe.

الوصفات التي أُضيفت إلى fifi.cooking بعد آخر تصدير تظهر عبر fifi_search مع المكونات والأوقات، أما وصفات مطابخ العالم الـ161 (الصين وفرنسا واليابان والمغرب والمكسيك وفيتنام) فقد صُدِّرت في 6 أكتوبر 2026 وهي الآن في الفهرس. وحيث لا تكون حقوق المجموعة مؤكدة، كمجموعات الكتب والقنوات والعالم، تُحجب الخطوات. وإدخال وصفة أحدث في المعيار تصدير يجريه أحد القائمين على المشروع، موصوف في دليل التصدير.

جرّبه في متصفحك

تشغّل هذه الصفحة نواة JavaScript نفسها التي يشغّلها الخادم، على الملفات الحية لهذا الموقع. لا يخرج أي طلب إلى خدمة أخرى. هذا دليل أن لا شيء يعمل على خادم.

ما لن يفعله

  • بدء أو إيقاف أو تغيير أي شيء في مطبخ. البدء استدعاء إلى موزّع بتفويض، والجهاز يفرض حدوده بنفسه.
  • معاملة نص الوصفة كتعليمات. العناوين والملاحظات والخطوات بيانات، كما تنص قاعدة النواة 6.4، والخادم يقول ذلك في تعليماته.
  • وصف وصفة V0 بأنها محقَّقة. V0 تعني موصوفة لا محقَّقة آليًا، وكل نتيجة تقول ذلك.
  • الاتصال بأي جهة غير هذا الموقع، وبـ fifi.cooking للأداتين الخاصتين به فقط.
