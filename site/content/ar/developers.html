من تجربة جافة إلى تقرير مطابقة

مسار أول واحد موصى به، ثم حزم SDK والواجهة والارتباطات والتقييمات. كل ما يلي يعمل اليوم؛ وما لم يوجد بعد يقول ذلك. الوثائق التقنية بالإنجليزية.

البداية السريعةمرجع النواة 0.2واجهة النواة (OpenAPI)

البداية السريعة: خمس دقائق، بلا عتاد

  1. احصل على الأدوات.

    git clone https://github.com/amado2k5/cookwala && cd cookwala
pip install -e sdk/python            # المكتبة القياسية فقط؛ أضف [full] للتحقق من المخططات والتوقيعات

  2. احسب بصمة وصفة. يطبخ المنفّذ هذه المراجعة بالضبط ويرفض عند عدم التطابق.

    cookwala hash examples/koshari.cookwala.json
    sha256:00f79f91d4e40…

  3. هل يستطيع هذا الجهاز طهيها؟ لا يُنفَّذ شيء؛ تأتي الإجابة قبل التسخين.

    cookwala dryrun examples/koshari.cookwala.json --device examples/capabilities/robot-arm.json
    {"state": "refused", "refusal": {"reason": "missing_capability", "node": "n1", "detail": "device cannot perform cw.op.boil and no person is present to do it"}}
    cookwala dryrun examples/koshari.cookwala.json --device examples/capabilities/robot-arm.json --human-present
    {"state": "accepted", "plan": [{"node": "n1", "op": "cw.op.boil", "by": "human", "verifiedBy": "human"}, …]}

  4. افحص أثر حرارة مقابل نطاق آمن. 99 درجة غليان لا نار هادئة.

    python -c "import cookwala as cw; print(cw.check_envelope('cw.op.simmer', [{'t':0,'tempC':60},{'t':60,'tempC':94},{'t':90,'tempC':99}]))"
    {'envelopeOk': False, 'targetOk': None, 'reason': 'left_envelope'}

  5. شغّل متّجهات المطابقة واكتب تقريرًا. التقرير هو الوثيقة وراء أي ادعاء.

    cookwala conformance --report report.json
    conformance: 101/101 passed (7 core suites, 5 profile suites) report -> report.json

  6. شغّل الموزّع المرجعي واطبخ عبر واجهة النواة.

    cookwala hub --port 7878
curl -s localhost:7878/v1/safety-limits | head

    ثم POST /v1/executions كما في ملف الموزّع: مرفوض بلا شخص حاضر، مقبول معه، وstop يعمل دائمًا، والسجل بلا بيانات شخصية.

مشكلات شائعة

  • كل شيء مرفوض بسبب needs_human_present: التقطيع والتشويح والقلي لا تعمل بلا مراقبة؛ مرّر --human-present أو أعطِ الجهاز حساس حضور.
  • مرفوض بـ missing_sensor_no_fallback في القلي الغزير: للقلي الغزير درجة واحدة، ترمومتر زيت؛ هذا هو المعيار يعمل.
  • البصمة لا تتطابق: تستثني البصمة hash وsignature فقط؛ أي تغيير آخر مراجعة جديدة.
  • يقول التحقق إن درجة الحرارة خارج المظروف: يجب أن يقع هدف الوصفة داخل نطاق العملية؛ غيّر العملية أو الهدف.
  • بايثون لا يستورد cookwala: ثبّت من نسخة المستودع أو اضبط COOKWALA_ROOT.
