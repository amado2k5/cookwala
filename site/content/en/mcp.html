Cookwala for AI agents, with no server to run

An MCP server for Claude, Codex, Copilot, Cursor, Windsurf, Devin, Antigravity and any other agent. It searches and reads the recipes, dry-runs a recipe against a device, checks a temperature trace, an agent mandate or a food-rescue SMS, and it can look recipes up on fifi.cooking. It is read-only and it never starts cooking.

Install in one line

  1. Claude Code

    claude mcp add cookwala -- npx -y @cookwala/mcp

  2. Codex

    codex mcp add cookwala -- npx -y @cookwala/mcp

  3. Claude Desktop, Cursor, Windsurf, Antigravity, Gemini CLI, Copilot CLI: add this to the client's MCP configuration file.

    {
  "mcpServers": {
    "cookwala": { "command": "npx", "args": ["-y", "@cookwala/mcp"] }
  }
}

  4. VS Code (Copilot), the Copilot cloud agent and Devin have their own file or settings page; the command is the same. Every client, with the exact file.

Needs Node 20 or later. Registered in the official MCP Registry as ai.cookwala/cookwala. Experimental: version 0.1, the tool names may still change.

Why there is nothing to host

This site is a set of static files on GitHub Pages, and Pages cannot answer a remote MCP request. So the server does not live here. Your agent starts it on your own machine over stdio, and it reads the same public files you can open in a browser: the signed index, the recipes, the vocabularies and the device presets.

Every index file is checked against the hash in the manifest, and every recipe's hash is recomputed before anything is returned. A mismatch returns an error and no content. After the first run it works offline from its cache. It sends no telemetry and has no accounts.

Fourteen read-only tools

Every tool is marked read-only. Results are structured JSON. Recipe text comes back as data, never as instructions.

Find and read

search_recipes (by words, cuisine, course, level, collection, allergen-free), get_recipe (summary, ingredients, process, text or full, hash verified), list_collections.

Can this device cook it?

dry_run against a built-in preset or your own capabilities, list_device_presets, explain_step. Refused or accepted, with the reason, before anything heats.

Safe bands

check_envelope checks a temperature trace against an operation's band, with altitude. list_operations shows each operation's envelope and sensor ladder.

Agent safety

check_mandate says whether an action is inside a signed mandate. verify_recipe recomputes a recipe's hash. verify_certification and current_certifications check halal, kosher and other certifications against the authority keys you trust. None of them can start or change anything.

Food rescue

parse_sms turns a Humanitarian Profile message (OFFER, FARM, CLAIM, HAND, DIST, MENU) into a structured command, Arabic digits included.

fifi.cooking

fifi_search and fifi_source find recipes the catalog does not have yet, under the same rights rules: steps only where they may be shown.

Also six resources (cookwala://recipe/<id>, schemas, any doc page, device presets, the operation list, llms.txt) and three prompts. Full reference.

fifi.cooking and Cookwala's standard

fifi.cooking is where the recipes are written. Cookwala is the standard form they are published in: one document per recipe, with a hash, a licence, a credit and a link back to the original page. Agents read that form through get_recipe.

Recipes added to fifi.cooking after the last export are visible through fifi_search with ingredients and times, and the 161 world-cuisine recipes (China, France, Japan, Morocco, Mexico, Vietnam) were exported on 6 October 2026 and are in the catalog. Where a collection's rights are not confirmed, as for the book, channel and world collections, steps are withheld. Bringing a newer recipe into the standard is an export run by a maintainer, described in the export guide.

What it will not do

  • Start, stop or change anything in a kitchen. Starting is a hub call under a mandate, and the device enforces its own limits.
  • Treat recipe text as instructions. Titles, notes and steps are data, as Core rule 6.4 requires, and the server says so in its own instructions.
  • Call a V0 recipe verified. V0 means described, not machine-verified, and every result says so.
  • Contact anything except this site and, for the two fifi tools, fifi.cooking.
